## 1. 背景与目标

### 1.1 现状痛点（为什么放弃旧认知）

| 问题 | 现状事实 |
|---|---|
| 砖内不拆 | Agent 框架一块砖 42 文件 10208 行，模块间直接 import 互调 |
| 分布散乱 | 砖分散在 `P.A.L.M_砖块/` 各子目录，主板单独一套，前端单文件 |
| 契约缺失 | 砖间走 `capabilities` 字典（弱契约），砖内用 `typing.Protocol`（无强制） |
| 两套模型 | 主板隐喻（总线/插槽/芯片）只存在于 manifest 标签，不约束代码结构 |
| 前端单体 | `frontend/index.html` 单文件，无界面拆分 |

### 1.2 目标（一步到位）

1. **最小颗粒度**：一切代码拆到「一个文件 = 一个职责」，函数 ≤50 行、文件 ≤500 行。
2. **统一存储**：全部原子模块进**一棵统一目录树**，按依赖方向分层，位置即架构。
3. **契约驱动**：模块之间只经 **ABC 抽象基类（Port）** 互连，零直接 import，漏实现即报错。
4. **插槽契约化**：主板隐喻保留为心智模型，但每个插槽 = 一个 Port 契约；USB 插槽 = 五接口 ABC。
5. **前端同构**：前端拆成一个一个界面，界面 = 模块，统一框架组装。
6. **可插拔装配**：bootstrap 装配层是唯一知道所有模块的地方，依赖注入，模块即插即用。

## 2. 核心原则（新地基）

| # | 原则 | 含义 | 强制手段 |
|---|---|---|---|
| 1 | 原子化 | 一个文件只做一件事 | 文件 ≤500 行，函数 ≤50 行（lint 校验） |
| 2 | 契约优先 | 模块间只依赖 Port，不依赖实现 | 目录只允许 import `ports/` 与同级以下层 |
| 3 | 依赖单向 | domain ← services ← adapters ← bootstrap，禁止反向 | 依赖方向 lint（import 检查脚本） |
| 4 | 统一存储 | 所有模块进 `P.A.L.M/` 统一树，不再散落 | 目录结构即架构，见第 3 节 |
| 5 | 装配唯一 | 只有 bootstrap 知道全部模块 | 除 bootstrap 外禁止全局注册表 |
| 6 | 接口强制 | 插槽用 ABC，不实现 abstractmethod 直接启动失败 | ABC 天然强制 |

**隐喻映射（保留心智模型，替换实现）**：

| 旧隐喻 | 新实现 |
|---|---|
| 砖块（brick） | 原子模块（module，位于统一目录树） |
| 总线（bus） | Port 契约类别（abc.ABC 基类族） |
| 插槽（cpu/ai/m2/chip/pcie/ram/sata/board/usb） | Port 实例化标签（模块声明实现的 Port） |
| 主板 | bootstrap 装配层 |
| 热插拔 | bootstrap 动态装配（模块注册表仅存在于装配层） |

> **已评审（2026-08-18）**：目录采用**纯工程命名**（`ports/`/`modules/`/`bootstrap/`），位置即架构；硬件隐喻（总线/插槽/芯片）**仅保留在 docstring 与 README** 作为心智映射，不进入目录名、文件名与类名。

## 4. 端口契约层（插槽 ABC 定义）

### 4.1 契约写法（统一模式）

```python
from abc import ABC, abstractmethod

class StoragePort(ABC):
    """存储插槽：任何实现该 ABC 的模块即「存储设备」，可插入 M.2 插槽。"""

    @abstractmethod
    def read_block(self, key: str) -> bytes: ...

    @abstractmethod
    def write_block(self, key: str, data: bytes) -> None: ...

    @abstractmethod
    def health(self) -> dict: ...
```

### 4.2 USB 设备插槽（五接口 ABC）· 首版纳入（已评审）

> **已评审（2026-08-18）**：DevicePort 纳入首版 Port 清单，契约先行——声卡/网卡当前虽 N/O（未授权禁用），但契约定义好后，日后恢复授权即插即用。

通用设备插槽（声卡/网卡/任何外设芯片实现它，即"插入 USB 插槽"）：

```python
class DevicePort(ABC):
    """设备插槽（USB）：五通道协议，任何外设芯片必须实现。"""

    @abstractmethod
    def ingest(self, payload: dict) -> None:
        """入站总线：承载控制/数据/外部事件，内部按类型路由。"""

    @abstractmethod
    def drain(self) -> list[dict]:
        """出站总线：抽取待发消息（心跳/数据包/出站数据）。"""

    @abstractmethod
    def heartbeat(self) -> str:
        """统一 UUID 存活信号（就绪/异常两态），消费者收不到即视为离线。"""

    @abstractmethod
    def control(self, code: str, decoder: dict) -> dict:
        """控制面：控制码 + 解码器单入口。"""

    @abstractmethod
    def data(self, payload: dict) -> bytes:
        """数据面：与控制面分离的载荷通道（音频/文本/二进制）。"""
```

| 插槽标签 | Port | 实现的模块（计划） | 说明 |
|---|---|---|---|

### 7.3 界面模块约定

- 未授权界面（声卡等）不装载（保持现有 N/O 策略）
