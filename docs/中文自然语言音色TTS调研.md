# 中文友好 · 自然语言自定义音色 TTS 模型调研

> 背景：已删除 QwenTTS（Qwen3-TTS-12Hz-1.7B VoiceDesign）。基准测试显示它在你的设备（RTX 5060 Laptop 8GB）上
> 平均端到端 42.6s、RTF 2.69、显存峰值 4.6GB——**慢到无法实时**。现需找一个「中文友好 + 自然语言描述音色 +
> 可流式 + 8GB 显存能跑」的开源替代品。调研日期：2026-08-15。

## 一、你的硬约束（来自本地基准）

| 约束 | 数值 | 含义 |
| --- | --- | --- |
| 显存 | 8GB（RTX 5060 Laptop） | 模型权重 + 推理需压在 ~6GB 内留余量 |
| 实时性 | GSV 已占 2.5GB 常驻 | 若与 GSV 共存，新模型显存须更省；否则走「离线高质量」定位 |
| 中文 | 主角扮演/对话 | 中文自然度、方言、多音字是硬指标 |
| 自然语言音色 | 用户明确要 | 能用「低沉沙哑男声」这类文字直接定音色，而非只给参考音频 |

## 三、结论与推荐

### 🥇 首选：CosyVoice 2（0.5B）

契合度最高的开源方案，理由：

1. **中文友好度第一梯队**：阿里通义 FunAudioLLM 出品，中文自然度接近真人、多音字/绕口令几乎不翻车；支持
   粤语、四川话等方言变体，跨语种克隆稳定（中文音色说英文音色一致）。
2. **自然语言自定义音色（你要的核心能力）**：提供两种指令模式——
   - `instruct` 模式：用「用开心的语气说」「语速慢一点」「播音腔」等自由文本调节情绪/方言/风格；
   - `instruct2` 模式（CosyVoice 2 专属）：把**零样本克隆 + 自然语言指令**结合，给一段参考音定音色，
     再用文字描述风格，二者解耦互不干扰。
   虽不像 Qwen3-TTS 的 VoiceDesign 那样「纯文字生成全新音色」（CosyVoice 2 的纯指令模式需内置/参考音色打底），
   但「参考音 + 自然语言风格指令」已覆盖绝大多数自定义音色场景，且可控性更强。
3. **可流式、可实时**：首包延迟约 1.5s，支持 `inference_zero_shot_streaming` 逐 chunk 输出，做实时对话不卡。
4. **显存友好**：0.5B 单路实时约 **4GB**，在你的 8GB 卡上可跑（若与 GSV 共存需错峰，或仅离线用）。
5. **工程成熟度最高**：Apache 2.0 可商用，官方提供 Docker Compose / WebUI / FastAPI / gRPC / **MCP Server**，
   集成成本低；社区教程多，踩坑少。
6. **生态对齐**：已有 `plugins/tts_sovits` 砖的「外部插件砖」模式，新增 CosyVoice 砖可套同一套接入骨架。

> 取舍：CosyVoice 2 的「纯文字生成全新音色」弱于 Qwen3-TTS VoiceDesign（它需要参考音打底）。
> 若你坚持要「完全不提供参考音、只靠一句话描述就造出新声音」，Qwen3-TTS 的 VoiceDesign 仍是独一档——
> 但你已经因为它的延迟/资源问题弃用了它。权衡之下，CosyVoice 2 是「中文质量 + 实时 + 可商用 + 生态」的最优折中。

### 🥈 备选：IndexTTS 2（重情感/时长场景）

- 适合：小说/情感号/有声书，需要 7 种情感独立控制、音色/情感解耦、Token 级时长对齐（配音口型同步）。
- 代价：FP16 约 **7.8GB 显存**（8GB 卡很紧，常需 12GB），且当前版本时长控制**未完全启用**，**不流式**，
  且需要参考音频（非纯 NL 造音）。作为实时对话 TTS 不如 CosyVoice 2。

### 不建议

- **Fish Speech 1.5**：多语言/社区强，但中文场景已被 CosyVoice 2 覆盖，且需 8GB+ 显存。
- **F5-TTS / Spark-TTS**：无自然语言音色控制，属「克隆派」，不满足你的核心诉求。

## 四、落地建议（若决定集成）

1. **复用现有骨架**：参照 `plugins/tts_sovits` 的「外部插件砖」模式，新建 `plugins/cosyvoice` 砖包 +
   独立 venv（Python 3.10，注意 `pynini` 用 conda 装），暴露与 GSV 一致的 TTS 能力接口。
2. **模式分层**：
   - 实时对话 → CosyVoice 2 流式（首包 1.5s）；
   - 高质量离线配音 → 1B 版或 IndexTTS 2（若重情感）。
3. **显存策略**：8GB 卡上 GSV(2.5G) + CosyVoice2-0.5B(4G) 共存偏紧，建议二选一常驻，或 CosyVoice 走
   按需拉起 + 空闲卸载（同 GSV 现有 AUTO_LAUNCH 机制）。
4. **自然语言音色入口**：在角色扮演/对话缝合引擎里，把「音色描述文本」映射为 CosyVoice 2 的
   `instruct_text`（如「用温柔低沉的语气说」），无需用户懂参数。
5. **合规**：Apache 2.0 可商用，保留 NOTICE；权重走 ModelScope 国内镜像下载更快。

## 五、一句话总结

**中文友好 + 自然语言自定义音色 + 可流式 + 8GB 显存**，2026 年开源首选 **CosyVoice 2（0.5B，Apache 2.0）**；
重情感/时长对齐再上 **IndexTTS 2**。两者都需参考音频打底（与 Qwen3-TTS 纯文字 VoiceDesign 的「无参考造音」不同，
但更可控、可商用、生态成熟）。
