**质量分解读（重要）**：
- **残留 `NotImplementedError`** 不应一律视为缺陷：主板（4 处）是抽象基类的方法桩（预期）；CosyVoice（9 处）是**训练专用依赖的纯 Python 占位 shim**（lightning / gdown / soxr 等），属「运行期零联网」的有意设计，真实推理路径不触发。
- **文档覆盖 / 类型标注偏低**是普遍现象（多数砖 < 0.5），是后续可改进项，不影响运行。
- **裸 except（bare except）**：除 GPT-SoVITS 外，其余 29 砖均为 0。GPT-SoVITS 的 24 处裸 except 全部来自其 vendored 上游 `gpt_sovits/`（GPT-SoVITS 仓库自身风格），非本仓自写逻辑，故其质量综合分为 0。
- **优雅降级（is_available）几乎全砖缺失**：仅 CosyVoice 实现。对依赖模型/外部服务的砖（语音、向量、记忆），建议统一加 `is_available()` 守卫，缺失时 capability 优雅降级（与之前安全加固风格一致）。
