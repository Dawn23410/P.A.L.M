> 取材日期：2026-09-23　｜　v1.0 → v2.0 变更：粒度由「按供应商」细化到「按模型」，

>
> **来源纪律**：只采信厂商官方开发者文档。第三方聚合站（wapi.cn、phpinfo 类、
> unifiedaihub、innfactoy 等）一律排除 —— 它们对扩展名和上限的描述常有陈旧项。
> 凡官方文档未写明或抓取失败处，一律标 **未查到**，不凭印象填。
>
> **抓取受限说明**（影响本表完整性，逐条列出）：
> - `docs.x.ai`（xAI）全站拦截，fetch 失败 ×4 → Grok 全字段 **未查到**
> - `platform.minimax.cn` 可取但规格页 404/仅发布日志 → MiniMax 全字段 **未查到**
> - `platform.openai.com/docs`、`docs.anthropic.com`、`ai.google.dev` 直连被拦截，
>   OpenAI / Anthropic / Gemini 数据取自其官方域的其他路径与搜索片段，个别 token 数
>   以第三方交叉印证补全，投产前应以各厂商 `GET /models` 复核
> - 火山引擎模型列表页为 SPA 未渲染正文，对话模型"文档理解"仅标 Supported，
>   未列扩展名与上限

## 十一、与内核现有规则的差异（待复审）

对照 `palm_llm/providers/profiles_data.py`（`as_of = 2026-09-23`），本轮调研发现：

| 项 | 现状 | 调研结果 | 处置建议 |
|---|---|---|---|
| DeepSeek 模型名 | 规则写 `deepseek-v4-pro` / `deepseek-v4-flash` | `deepseek-v4-flash` 已下线，现用 `deepseek-flash`（V4.1-Flash） | 正则加 `deepseek-flash` 候选，保留旧名兼容 |
| `deepseek-reasoner` | 规则仍在 | 2026-07-24 已弃用，按 flash 思考模式路由 | 保留规则（仍可路由），补 `note` 说明弃用 |
| Kimi k2.5 | 规则在 | 2026-08-31 已下线 | 规则保留（旧调用方不至于炸），补 `note` |
| Claude `opus-4-5` | 规则在 | 不在当前在售阵容表 | 保留（老账号可能仍可调） |
| Doubao 思考档位 | 规则写 `doubao-seed-character` 不支持思考 | Seed 2.1 全系支持 `reasoning_effort` 七档 | 新增 Seed-2.1 系规则 |
| Anthropic `effort` | 规则只有 adaptive + forbid budget | 原生用 `output_config.effort`（low/medium/high/xhigh/max） | 已在 `anthropic.py` 实现；规则可补 `effort_allowed` |
| Qwen omni-turbo | 规则写"不支持 enable_thinking" | 该模型名已不在当前文档 | 规则保留，补 `note` |

> 复审口径：模型下线不等于规则要删 —— 规则删掉会让仍在用旧名的调用方直接**无法匹配**，
> 而匹配不上只会回落到 Profile 默认（不会报错）。故一律**保留 + 补 note**，
> 让"知道它下线了"这件事留在数据里。
