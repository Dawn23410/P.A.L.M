## 1. OpenAI

**图片**：gpt-4o 及以后（GPT-5 系列、GPT-5.6 Sol/Terra/Luna、o1 均标 "Image Input only"）。

**文件输入**（`input_file` / Chat Completions 的 `{"type":"file"}`）：

| 类别 | 扩展名 |
|---|---|
| PDF | `.pdf` |
| 表格 | `.xla .xlb .xlc .xlm .xls .xlsx .xlt .xlw` / `.csv .tsv .iif` + Google Sheets |
| 富文档 | `.doc .docx .dot .odt .rtf`、Pages、Google Docs |
| 演示 | `.pot .ppa .pps .ppt .pptx .pwz .wiz`、Keynote、Google Slides |
| 文本与代码 | `.asm .bat .c .cc .conf .cpp .css .cxx .def .dic .eml .h .hh .htm .html .ics .ifb .in .js .json .ksh .list .log .markdown .md .mht .mhtml .mime .mjs .nws .pl .py .rst .s .sql .srt .text .txt .vcf .vtt .xml` |

**限制**：单文件 **< 50 MB**，请求内所有文件**合计 < 50 MB**。
**三种传入方式**：base64 data URI / Files API 的 `file_id`（`purpose=user_data`）/ 外部 URL。
**要点**：PDF 解析 = 抽取文本 **+ 页面图像**，**要求 vision 能力模型**；Responses API 可设 `detail: auto|low|high` 控制页面图像细节。
**File Search（向量库）**：单文件最大 **512 MB**，每文件 ≤ **5,000,000 tokens**。

## 2. Anthropic

**PDF 支持**（官方 "PDF support" 页）：

| 要求 | 限制 |
|---|---|
| 最大请求大小 | **32 MB**（因平台而异） |
| 每请求最大页数 | **600 页**（上下文窗口 < 1M 时为 **100 页**） |
| 格式 | 标准 PDF（**无密码/加密**） |

- **所有活跃模型**支持 PDF 处理；依赖 vision 能力，受视觉任务同样的限制。
- 三种传入：URL、`document` content block（base64）、Files API `file_id`。
- 上下文窗口：**Opus 4.6/4.7/4.8/5、Sonnet 4.6/5、Fable/Mythos 5.x = 1M**；其他（含 Sonnet 4.5）= **200k**。
- 单请求最多 **600 张图像或 PDF 页**（200k 上下文模型为 100）。
- 1M 上下文模型单请求最多 **128k** 输出。
- ⚠️ 经 **Amazon Bedrock Converse API** 时有两种模式：Document Chat（仅文本提取，3 页≈1000 token，默认）与 PDF Chat（完整视觉，3 页≈7000 token，**需启用 citations**）。
- ❌ **只支持 PDF**，不支持 Office/表格/代码文件直接输入。

## 3. Google Gemini

**输入方式与限制**（官方 "File input methods"）：

| 方式 | 最大文件 | 持久化 |
|---|---|---|
| Inline data | **100 MB / 请求**（**PDF 50 MB**） | 无 |
| Files API 上传 | **2 GB / 文件，20 GB / 项目** | **48 小时** |
| GCS URI 注册 | 2 GB / 文件 | 无（可注册到 30 天） |
| 外部 URL | 100 MB / 请求 | 无 |

**PDF**：上限 **50 MB 或 1000 页**（inline 与 Files API 同）。每页 ≈ **258 tokens**；页面缩放到最大 **3072×3072**、最小放大到 **768×768**。

**支持的 MIME 类型**：

| 类别 | MIME |
|---|---|
| 文本 | text/html, text/css, text/plain, text/xml, text/csv, text/rtf, text/javascript |
| 应用 | application/json, application/pdf |
| 图片 | image/bmp, image/jpeg, image/png, image/webp |
| 视频 | video/mp4, video/mpeg, video/quicktime, video/avi, video/x-flv, video/mpg, video/webm, video/wmv, video/3gpp |

**Gemini 3 新特性**：`media_resolution` = low/medium/high（按 media part 粒度）；PDF 的**原生文本被提取且不计费**；PDF 页面 token 计入 **IMAGE** modality。

⚠️ **只有 PDF 有真正的文档视觉理解**；TXT / Markdown / HTML / XML 等**只提取纯文本**，图表、排版、标签全部丢失。

## 4. 智谱 GLM

**视觉模型**：

| 模型 | 输入模态 | 上下文 | 备注 |
|---|---|---|---|
| **GLM-4.5V** | **视频、图像、文本、文件** | 64K | 106B 总参/12B 激活；支持 Thinking/Non-Thinking 开关 |
| **GLM-4.6V**（2025-12-08） | 视觉 | 视觉上下文 **128k** | 单次可处理约 **150 页复杂文档、200 页 PPT 或一小时视频** |

**知识库上传限制**（官方 "知识问答" 页）：

| 类型 | 格式 | 大小 | 数量 |
|---|---|---|---|
| 图片 | JPG / JPEG / PNG 等 | 单图 ≤ **5 MB** | 最多 **150 张** |
| 视频 | MP4 等 | 单个 ≤ **200 MB** | 最多 **1 个** |
| 文件 | PDF / Word / PPT / Text 等 | 单个 ≤ **50 MB** | 最多 **5 个**（单次最多解析 150 张图片） |

**Files API（`purpose="file-extract"`）**：
格式 = `.PDF .DOCX .DOC .XLS .XLSX .PPT .PPTX .PNG .JPG .JPEG .CSV .PY .TXT .MD .BMP .GIF`；
**文件 ≤ 50 MB、图片 ≤ 5 MB、总数 ≤ 100 个**。
深度解析（PDF 等）按 **0.12 元/页** 计费；图片理解免费。

## 5. 通义千问（阿里云百炼）

**图像格式**（官方 "模型调优简介 / Visual understanding"）：

| 分辨率 | 支持格式 |
|---|---|
| < 4K（3840×2160） | BMP / JPEG(.jpe,.jpeg,.jpg) / PNG / TIFF(.tif,.tiff) / WEBP / **HEIC** |
| 4K ~ 8K | **仅 JPEG / JPG / PNG** |

**图像大小**：

| 传入方式 | 限制 |
|---|---|
| 公网 URL | Qwen3.8/3.7/3.6/3.5/Qwen3-VL 系列单图 ≤ **20 MB**；其他 ≤ 10 MB |
| 本地路径 | 单图 ≤ **10 MB** |
| Base64（OpenAI 兼容 / DashScope） | 原始文件 ≤ 20 MB（3.8/3.7/3.6/3.5/Qwen3-VL）、其他 ≤ 10 MB；**编码后 Data URI ≤ 20 MB** |
| Base64（**Anthropic 兼容接口**） | ⚠️ **请求体整体 ≤ 6 MB**，多图共享额度 |

**图像几何**：宽高均 ≥ 10 px；长宽比 ≤ 200:1；推荐 ≤ 8K（7680×4320）。
**像素/token**：多数模型单图上限 **1600 万像素**；token = `h×w/(32×32) + 2`。
`max_pixels`：Qwen3-VL 默认 2621440、上限 16777216；`vl_high_resolution_images=True` 时固定上限（Qwen3-VL 等 16777216，其他 12845056）。

**视频**：

| 时长 / 大小 | 模型 |
|---|---|
| **2 小时 / 2 GB** | qwen3.8-max、qwen3.8-max-0902、qwen3.8-flash、qwen3.7-plus、qwen3.6-plus、qwen3.7-flash、qwen3.6-flash、qwen3.5-plus、qwen3.5-flash |
| **1 小时 / 2 GB** | qwen3-vl-plus、qwen3-vl-flash、qwen3.5-omni-plus、qwen3.5-omni-flash（后者另支持音频输入） |

**数量上限**：qwen3.8-max/3.8-flash/3.7-plus 单请求最多 **2048 张图 / 64 个视频**；qwen3.7-flash **256 张 / 64 个**。

**文档**：`qwen3.5-ocr` 专做文档/表格/试卷/手写 OCR；通用图片文字提取用 qwen3.7-plus/flash。
⚠️ **没有 OpenAI 那样的"文件直接输入"**，文档需先转图片或走 OCR 模型。

## 7. 对内核的直接影响

1. **`providers/multimodal.py` 只有 `openai` / `anthropic` 两种 mode**，没有 Gemini 的 `inlineData`、`fileData`。上 Gemini 通道时必须补。
2. **"文档输入"不是通用能力**：OpenAI 支持 5 大类格式、Anthropic **只支持 PDF**、Gemini **只有 PDF 有视觉理解**（其他退化为纯文本）、通义**根本没有文件直传**。→ 不能做成统一接口抽象，必须按供应商能力**显式声明**。
3. **大小限制差异巨大**（6 MB ~ 2 GB），且**同一厂商内不同传入方式限制不同**（通义 Anthropic 兼容接口 6 MB vs OpenAI 兼容 20 MB）。
4. 建议能力描述符字段：`supports_vision` / `supports_video` / `supports_audio` / `doc_mimes: tuple` / `max_file_mb` / `max_pages` / `max_images`。

## 8. 诚实边界

1. **全部为官方文档页面抓取，无一家实机验证**（无 API key）。
2. **本轮未回抓**：豆包（火山）、腾讯混元、Moonshot 官网、MiniMax 文件上传——这几家的格式与大小限制缺失，已在 §6 逐条标注。
3. Kimi 视觉能力是**百炼渠道的间接证据**，非 Moonshot 官网原文。
4. 各家能力迭代快（如 Gemini 3 新增 `media_resolution`、Anthropic 把媒体上限从 100 提到 600），规则须带 `as_of` 并定期复审。
