# 砖块设计文档 - 23 game 砖（游戏化与挑战系统）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/game/`
> 定位：游戏化互动、挑战任务、积分系统

---

## 功能支持

game 砖为 P.A.L.M 增加游戏化元素，让用户与 AI 的互动更有趣。

### 23.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 创建挑战 | `game.create_challenge(type, params)` | 新建挑战 |
| 列出挑战 | `game.list_challenges()` | 当前可用挑战 |
| 接受挑战 | `game.accept(challenge_id)` | 用户接受 |
| 提交结果 | `game.submit(challenge_id, result)` | 提交答案 |
| 评估结果 | `game.evaluate(challenge_id, result)` | 自动评估 |
| 积分增减 | `game.add_points(user, points)` | 加分 |
| 积分查询 | `game.get_points(user)` | 当前积分 |
| 排行榜 | `game.leaderboard(scope)` | 排名 |
| 成就系统 | `game.check_achievement(user)` | 检查解锁 |
| 解锁成就 | `game.unlock(user, achievement)` | 解锁 |

### 23.2 挑战类型

| 类型 | 例子 | 评估方式 |
|---|---|---|
| 知识问答 | "Python 是什么" | 关键词匹配 |
| 编码挑战 | "写一个快排" | 代码运行 + 测试 |
| 推理挑战 | "这道数学题怎么做" | 答案匹配 |
| 创意挑战 | "为这个产品写 slogan" | LLM 评分 |
| 日常任务 | "今天和 AI 聊了 10 句" | 计数 |
| 习惯养成 | "连续 7 天打卡" | 连续计数 |

### 23.3 积分与成就

| 维度 | 例子 |
|---|---|
| 等级 | LV.1 ~ LV.100（积分门槛） |
| 称号 | 新手 / 学徒 / 大师 / 宗师 |
| 成就 | 首次对话 / 100 天活跃 / 1000 次工具调用 |
| 排行榜 | 全局 / 好友 / 周 / 月 |

### 23.4 创新设计

- **多样化挑战**：知识 / 编码 / 推理 / 创意 / 日常
- **自动评估**：挑战结果自动评估，无需人工
- **积分 + 成就双驱动**：积分激励持续参与，成就激发成就感
- **排行榜**：社交化竞争
- **等级解锁**：高级功能需达到等级
- **挑战模板**：用户可自定义挑战

## 关键设计决策

### 决策 1：多样化挑战
不同类型挑战满足不同用户偏好。

### 决策 2：自动评估
无需人工评判，编码挑战运行测试，创意挑战用 LLM 评分。

### 决策 3：积分 + 成就双驱动
积分激励持续参与，成就激发成就感。

### 决策 4：等级解锁
高级功能（自定义角色 / 自定义挑战）需达到等级，激励用户成长。

### 决策 5：挑战模板
用户可自定义挑战（"每天背 10 个单词"），扩展性强。

### 决策 6：反作弊
检测异常答题速度 / 答案相似度，避免刷分。
