# 砖块设计文档 - 17 scheduler 砖（任务调度）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/scheduler/`
> 定位：定时任务、周期任务、cron 调度

---

## 功能支持

scheduler 砖负责 P.A.L.M 的所有定时 / 周期任务调度。

### 17.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 注册任务 | `scheduler.add(name, cron, callback)` | 加入调度 |
| 列出任务 | `scheduler.list()` | 返回所有任务 |
| 启用 / 禁用 | `scheduler.enable / disable(name)` | 切换状态 |
| 立即触发 | `scheduler.trigger(name)` | 立即执行一次 |
| 删除任务 | `scheduler.remove(name)` | 删除 |
| 任务历史 | `scheduler.history(name)` | 执行历史 |
| 下次执行 | `scheduler.next_run(name)` | 返回下次时间 |
| 任务优先级 | `scheduler.priority(name, level)` | 设置优先级 |

### 17.2 调度粒度

- **最小间隔**：10 分钟（防过频）
- **支持类型**：一次性 / 周期 / cron
- **时区支持**：IANA 时区（`Asia/Shanghai`）
- **节假日跳过**：可选跳过节假日
- **重叠处理**：上次未完成时跳过本次 / 排队

### 17.3 创新设计

- **持久化**：任务列表存 storage 砖，进程重启后恢复
- **执行历史**：每次执行记录入库
- **优先级队列**：高优先级任务先执行
- **失败重试**：可配置重试次数
- **失败告警**：连续失败 N 次后告警
- **重叠处理策略**：跳过 / 排队 / 并发
- **资源感知**：低资源时延后非关键任务

## 关键设计决策

### 决策 1：持久化
任务列表存 storage 砖，进程重启不丢失。

### 决策 2：执行历史
每次执行记录入库（成功 / 失败 / 耗时 / 输出），便于分析。

### 决策 3：优先级队列
高优先级任务先执行（高 = 关键任务，如备份；低 = 平凡任务，如清理）。

### 决策 4：失败重试 + 告警
单次失败重试 N 次；连续失败 M 次后告警。

### 决策 5：重叠处理
可配置跳过 / 排队 / 并发，避免"上次还没跑完就触发下一次"。

### 决策 6：资源感知
低资源时延后非关键任务，避免雪崩。

### 决策 7：cron 表达式限制
不支持"每月第三个周五"等复杂规则（标准 5 字段 cron），仅支持基本周期。

## 性能与边界
