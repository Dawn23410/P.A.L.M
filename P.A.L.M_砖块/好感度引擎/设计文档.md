# 砖块设计文档 - 12 affinity 砖（好感度与人际关系）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/affinity/`
> 定位：用户与 AI / 角色之间的好感度与人际关系建模

---

## 功能支持

affinity 砖模拟人际关系动态变化，支持好感度、信任度、亲密度等多维度调节。

### 12.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 获取好感度 | `affinity.get(user_id, character_id)` | 返回当前多维分数 |
| 增加好感 | `affinity.increase(user_id, character_id, reason)` | 显式调节 |
| 减少好感 | `affinity.decrease(user_id, character_id, reason)` | 显式调节 |
| 隐式调节 | `affinity.implicit_adjust(events)` | 根据事件自动调节 |
| 关系阶段 | `affinity.relationship_stage(affinity_score)` | 陌生人 / 熟人 / 朋友 / 亲密 |
| 关系历史 | `affinity.history(user_id, character_id)` | 返回变化曲线 |
| 触发对话策略 | `affinity.dialogue_strategy(stage)` | 根据阶段返回对话风格 |
| 好感度回滚 | `affinity.rollback(user_id, character_id, time)` | 回到指定时间点 |

### 12.2 多维关系

| 维度 | 范围 | 含义 |
|---|---|---|
| 好感 | -100 ~ 100 | 喜欢程度 |
| 信任 | 0 ~ 100 | 信任程度 |
| 亲密 | 0 ~ 100 | 亲密程度 |
| 尊重 | 0 ~ 100 | 尊重程度 |
| 警惕 | 0 ~ 100 | 警惕程度（越高越生疏） |

### 12.3 隐式调节事件

| 事件 | 影响维度 | 调节幅度 |
|---|---|---|
| 用户表达感谢 | 好感 +5, 信任 +2 | 0~10 |
| 用户抱怨 | 好感 -3, 警惕 +5 | 0~10 |
| 角色帮助用户成功 | 信任 +8, 好感 +3 | 0~10 |
| 用户爽约 | 信任 -10, 警惕 +8 | 0~10 |
| 长期未互动 | 好感 -1 / 7天, 信任 -0.5 / 7天 | 衰减 |
| 情绪共振（用户悲伤时角色温柔） | 好感 +2, 亲密 +3 | 0~5 |

### 12.4 关系阶段

| 好感度 | 阶段 | 对话风格 |
|---|---|---|
| < 10 | 陌生人 | 礼貌、保持距离 |
| 10 ~ 30 | 初识 | 好奇、试探 |
| 30 ~ 50 | 熟人 | 友好、开始开玩笑 |
| 50 ~ 70 | 朋友 | 关心、主动分享 |
| 70 ~ 85 | 亲近 | 撒娇、关心、玩笑 |
| > 85 | 亲密 | 完全信任、亲密互动 |

### 12.5 创新设计

- **多维而非单维**：信任 ≠ 好感（用户可能信任但不喜欢）
- **隐式自动调节**：减少用户手动配置负担
- **关系阶段对应风格**：自动切换对话语气
- **衰减机制**：长期不互动关系自然淡化（更真实）
- **历史可回滚**：避免误操作永久破坏关系
- **情绪共振加成**：角色对用户情绪做出合适回应时额外加分

## 关键设计决策

### 决策 1：多维而非单维
单维"好感度"无法描述"信任但不喜欢"等复杂关系，多维更真实。

### 决策 2：隐式自动调节
LLM 行为（帮助成功 / 误操作）自动调节好感度，简化用户配置。

### 决策 3：阶段对应风格
关系阶段自动驱动对话风格，LLM 收到 system prompt 注入。

### 决策 4：衰减机制
长期不互动关系自然淡化，避免"永远高好感"的不真实感。

### 决策 5：历史可回滚
误操作可恢复到指定时间点。**好处**：调试 / 用户投诉时易修复。

### 决策 6：情绪编码非对称（仅正向激活）
仅 v ≥ 0 的正向情绪激活"经验合并"，避免负向情绪衰减被"刷屏"式负面事件覆盖。

## 性能与边界

- 关系读延迟：< 1ms（内存缓存）
- 关系写延迟：< 5ms
- 衰减周期：7 天
- 单用户最大关系数：100
