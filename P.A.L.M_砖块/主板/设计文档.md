# 砖块设计文档 - 24 board 砖（看板 / 任务面板）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/board/`
> 定位：多任务管理、状态跟踪、可视化面板

---

## 功能支持

board 砖为 P.A.L.M 提供多任务管理与可视化面板能力。

### 24.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 创建任务 | `board.create(title, assignee, due)` | 新建任务 |
| 列出任务 | `board.list(filter)` | 按状态 / 负责人筛选 |
| 更新任务 | `board.update(task_id, **fields)` | 修改字段 |
| 删除任务 | `board.delete(task_id)` | 删除 |
| 移动任务 | `board.move(task_id, column)` | 状态流转 |
| 看板视图 | `board.kanban_view()` | 列展示 |
| 甘特图 | `board.gantt_view()` | 时间线 |
| 任务依赖 | `board.set_dependency(task_id, depends_on)` | 设置依赖 |
| 子任务 | `board.add_subtask(task_id, subtask)` | 拆分子任务 |
| 评论 | `board.comment(task_id, comment)` | 添加评论 |
| 历史 | `board.history(task_id)` | 变更历史 |

### 24.2 任务状态

| 状态 | 含义 |
|---|---|
| `todo` | 待办 |
| `in_progress` | 进行中 |
| `blocked` | 阻塞 |
| `review` | 待审 |
| `done` | 完成 |
| `cancelled` | 取消 |

### 24.3 看板列

- 默认：todo / in_progress / blocked / review / done
- 自定义：用户可加列（如"待测试"）
- WIP 限制：每列最多任务数（避免过载）

### 24.4 创新设计

- **多视图**：看板 / 列表 / 甘特图
- **任务依赖**：DAG 依赖关系
- **子任务**：嵌套拆解
- **WIP 限制**：避免单列任务堆积
- **评论 + 历史**：协作能力
- **自动化规则**：状态变化触发动作
- **与 Agent 集成**：Agent 可作为任务执行者

## 关键设计决策

### 决策 1：多视图
看板适合日常 / 列表适合总览 / 甘特图适合排期。

### 决策 2：任务依赖 DAG
复杂任务可表达依赖，避免"前置任务未完成就启动后置"。

### 决策 3：WIP 限制
每列最多任务数（默认 5），避免"在途任务过多"。

### 决策 4：与 Agent 集成
Agent 可作为任务执行者（自动接收 todo 任务并执行）。

### 决策 5：自动化规则
状态变化触发动作（如"任务进入 review 自动通知 reviewer"）。

### 决策 6：评论 + 历史
协作能力 + 可追溯。

- 子任务嵌套：3 层
- 历史保留：90 天
