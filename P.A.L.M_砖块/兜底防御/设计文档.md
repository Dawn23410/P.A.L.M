# 砖块设计文档 - 13 safety 砖（安全护栏）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/safety/`
> 定位：危险操作拦截 + 内容安全审查

---

## 功能支持

safety 砖是 P.A.L.M 的最后一道防线，承担命令黑名单、敏感内容检测、危险操作拦截。

### 13.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 命令黑名单 | `safety.check_command(cmd)` | 拦截危险 shell 命令 |
| 路径黑名单 | `safety.check_path(path)` | 拦截越界路径 |
| 内容审查 | `safety.check_content(text)` | 检测敏感内容 |
| 工具白名单 | `safety.check_tool(tool_name)` | 检查工具是否在白名单 |
| API Key 泄露检测 | `safety.check_api_leak(text)` | 检测硬编码的 Key |
| PII 检测 | `safety.check_pii(text)` | 检测个人隐私信息 |
| 危险操作降级 | `safety.demote(risk_level)` | 强制人工确认 |
| 审计日志 | `safety.audit_log(event)` | 记录所有拦截事件 |

### 13.2 风险等级

| 等级 | 例子 | 处理 |
|---|---|---|
| `low` | 读文件、列表 | 直接放行 |
| `medium` | 写文件、HTTP 请求 | 记录日志 |
| `high` | 删文件、运行命令 | 弹窗确认 |
| `critical` | 删系统文件、格式化磁盘 | 拒绝执行 |

### 13.3 危险命令黑名单

| 类别 | 命令 |
|---|---|
| 系统破坏 | `rm -rf /`, `mkfs`, `dd if=` |
| 权限提升 | `sudo`, `su`, `chmod 777 /` |
| 网络下载 | `curl \| bash`, `wget \| sh` |
| 后门 | `nc -l`, `netcat`, `bash -i` |
| 关机 | `shutdown`, `reboot`, `halt` |
| 注册表 | `reg delete`, `bcdedit` |
| Windows 关键 | `format`, `diskpart`, `cipher /w:` |

### 13.4 创新设计

- **fail-closed**：安全闸门故障时拦截操作（绝不 fail-open）
- **风险等级分级**：低/中/高/严重四级处理
- **命令 + 路径 + 内容三道审查**：全方位防护
- **API Key 泄露检测**：检测硬编码 Key
- **PII 脱敏**：检测身份证 / 银行卡 / 手机号等
- **审计日志完整**：所有拦截事件入库可追溯
- **白名单 + 黑名单并存**：默认黑名单，用户可加白名单

## 关键设计决策

### 决策 1：fail-closed
安全闸门故障（配置加载失败 / 规则解析错误）时**默认拒绝**。**好处**：避免"闸门失效 + 危险操作"双重事故。

### 决策 2：风险等级分级
低/中/高/严重四级，对应直接放行 / 记录日志 / 弹窗确认 / 拒绝执行。

### 决策 3：命令 + 路径 + 内容三道审查
shell 命令黑名单 + 文件路径沙箱 + 文本内容 PII 检测，纵深防御。

### 决策 4：API Key 泄露检测
正则检测 LLM 输出中是否包含明文 Key（sk-、AIza、ghp_ 等前缀），命中则告警并脱敏。

### 决策 5：审计日志完整
所有拦截事件入库，含时间、用户、原始命令、拦截原因，事故追溯。

### 决策 6：白名单 + 黑名单并存
默认黑名单（拒绝已知危险），用户可加白名单（允许特定操作）。

## 性能与边界

- 命令检查延迟：< 1ms
- 内容审查延迟：< 50ms（关键词）/ < 500ms（LLM 审查）
- 审计日志保留：90 天
- 风险等级：4 档
