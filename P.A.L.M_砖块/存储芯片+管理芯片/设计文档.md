# 砖块设计文档 - 08 storage 砖（持久化层）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/storage/`
> 定位：所有数据的持久化后端（KV / 时序 / 二进制）

---

## 功能支持

storage 砖是 P.A.L.M 的"硬盘"，提供统一的 KV / 时序 / 二进制存储接口。

### 8.1 三类存储

| 类型 | 用途 | 实现 | 接口 |
|---|---|---|---|
| **KV 存储** | 配置、用户画像、Atlas 静态地图、路径记忆 | SQLite / JSON 文件 | `kv.get/set/delete/list` |
| **时序存储** | 消息流、对话日志、监控指标 | 追加日志 + 索引 | `ts.append/query/range` |
| **二进制存储** | 截图、音频、模型权重 | 文件系统 | `blob.put/get/delete` |

### 8.2 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| KV 读 | `kv.get(key, default)` | 读取字符串值 |
| KV 写 | `kv.set(key, value, ttl=None)` | 写值，可选 TTL |
| KV 删 | `kv.delete(key)` | 删除 |
| KV 列 | `kv.list(prefix)` | 列出键 |
| 时序追加 | `ts.append(stream, event)` | 追加事件 |
| 时序查询 | `ts.query(stream, start, end, limit)` | 范围查询 |
| 二进制写 | `blob.put(key, bytes)` | 写二进制 |
| 二进制读 | `blob.get(key)` | 读二进制 |
| 备份 | `storage.backup()` | 全量备份到指定目录 |
| 恢复 | `storage.restore(backup_path)` | 从备份恢复 |
| 容量监控 | `storage.usage()` | 返回各分类占用 |

### 8.3 数据分类

| 分类 | 用途 | 大小估计 |
|---|---|---|
| `gui_atlas` | 静态地图（软件结构） | ~10MB / 软件 |
| `gui_routes` | 路径记忆（执行经验） | ~1MB / 软件 |
| `gui_transitions` | 转移规律 | ~1MB / 软件 |
| `gui_coord_memory` | 归一化坐标 | ~5MB / 软件 |
| `conversations` | 会话消息 | ~100KB / 会话 |
| `user_profiles` | 用户画像 | ~10KB / 用户 |
| `blobs` | 截图 / 音频 | 按需 |
| `metrics` | 监控指标 | 滚动 7 天 |

### 8.4 创新设计

- **统一抽象层**：所有存储走同一接口，新增后端（Redis / Postgres）只需实现一个 adapter
- **分类管理**：数据按分类目录分桶，便于备份 / 清理
- **TTL 支持**：KV 存储可设过期时间（用于缓存）
- **追加日志**：消息流用追加日志而非 UPDATE，写入高效
- **本地优先**：默认本地文件存储，不依赖外部数据库
- **零依赖启动**：无需安装数据库，开箱即用
- **fail-soft**：磁盘满 / 权限错误时返回失败，不抛异常

## 关键设计决策

### 决策 1：本地优先 + 零依赖
默认 SQLite / JSON 文件，无需安装数据库，简化部署。**好处**：开箱即用；可离线运行。

### 决策 2：分类目录分桶
不同类型数据（gui_atlas / conversations / blobs）走不同子目录，备份 / 清理独立。**好处**：清理 GUI 自动化数据不影响对话。

### 决策 3：追加日志写消息
消息流用追加日志而非 UPDATE，避免数据库写锁争用。

### 决策 4：TTL 支持
KV 存储可设过期，用于短期缓存（情绪缓冲、临时任务状态等）。

### 决策 5：fail-soft
所有存储失败返回 False / None，不抛异常。**好处**：磁盘满 / 权限错误不阻塞主流程。

### 决策 6：分类备份 / 恢复
备份可指定分类（只备份 gui_atlas），恢复支持部分恢复。**好处**：灾难恢复灵活。

## 性能与边界

- KV 读延迟：< 1ms
- 时序追加：< 5ms
- 二进制读：< 10ms（小文件）/< 100ms（> 10MB）
- 默认数据目录：`$DATA_DIR/storage/`
- 单数据库最大：1GB（超出分文件）
