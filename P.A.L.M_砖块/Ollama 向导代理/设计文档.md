# 砖块设计文档 - 22 ollama 砖（本地 LLM 接入）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/ollama/`
> 定位：本地 LLM 统一接入、模型管理、推理优化

---

## 功能支持

ollama 砖把本地 LLM（Ollama）封装为 P.A.L.M 统一接口，屏蔽底层差异。

### 22.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 检测 Ollama | `ollama.is_running()` | 检查服务是否在跑 |
| 启动 Ollama | `ollama.start()` | 自动启动服务 |
| 列出模型 | `ollama.list_models()` | 已下载模型 |
| 拉取模型 | `ollama.pull(name)` | 下载模型 |
| 删除模型 | `ollama.delete(name)` | 删除 |
| 加载模型 | `ollama.load(name)` | 预热到内存 |
| 同步推理 | `ollama.complete(name, messages)` | 阻塞等结果 |
| 流式推理 | `ollama.stream(name, messages)` | 逐 token |
| 嵌入向量 | `ollama.embed(name, texts)` | 返回向量 |
| 健康检查 | `ollama.health_check()` | 探测服务 |

### 22.2 支持模型

| 模型 | 大小 | 用途 |
|---|---|---|
| qwen2.5:7b | 4.7GB | 通用对话 |
| qwen2.5:14b | 9GB | 更高质量 |
| llama3.1:8b | 4.9GB | 多语言 |
| deepseek-v2:16b | 8.9GB | 中文友好 |
| qwen2-vl:7b | 5GB | 视觉 |
| bge-m3 | 2.2GB | 嵌入 |

### 22.3 离线降级

- 网络不可用时自动切本地
- 本地模型未启动时自动启动
- 启动失败时返回明确错误

### 22.4 创新设计

- **自动检测 + 自动启动**：零配置使用
- **统一接口**：与云端 LLM（GPT-4o / DeepSeek）走同一接口
- **模型预热**：常用模型预加载到内存
- **健康检查 + 自动重连**：服务异常时自动重连
- **流式推理优化**：本地推理也可流式输出
- **GPU 加速检测**：自动检测 CUDA / Metal 支持

---

## 关键设计决策

### 决策 1：自动启动
用户无需手动启动 Ollama，P.A.L.M 检测到本地模型需求时自动启动。

### 决策 2：统一接口
与云端 LLM 走同一接口，LLM 切换对上层透明。

### 决策 3：模型预热
常用模型启动时预加载，避免首次调用延迟。

### 决策 4：自动重连
Ollama 服务异常退出时自动重连。

### 决策 5：GPU 加速
自动检测 CUDA / Metal 启用 GPU 加速。

### 决策 6：流式推理
本地推理也支持流式输出，UX 与云端一致。

## 性能与边界

- 单次推理延迟：~500ms（7B 模型）
- 显存占用：~6GB（7B 模型）
- 模型下载：1-10GB
- 启动时间：~10s
