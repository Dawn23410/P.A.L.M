# 砖块设计文档 - 19 parse 砖（内容解析）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/parse/`
> 定位：多格式内容解析、文档加载、文本提取

---

## 功能支持

parse 砖负责把各种格式的输入内容解析为结构化数据。

### 19.1 支持格式

| 格式 | 解析能力 | 用途 |
|---|---|---|
| PDF | 文本 + 表格 + 图片提取 | 文档问答 |
| Word | 段落 + 表格 + 样式 | 文档编辑 |
| Excel | 单元格 + 公式 + 图表 | 数据分析 |
| PPT | 幻灯片 + 备注 | 演示文稿 |
| Markdown | 标题 + 段落 + 代码块 | 笔记 |
| HTML | DOM + 文本提取 | 网页抓取 |
| JSON | 树形结构 | 配置 / API |
| YAML | 树形结构 | 配置 |
| CSV | 二维表 | 数据 |
| 图片 | OCR + 视觉描述 | 截图理解 |
| 音频 | ASR + 说话人识别 | 语音输入 |
| 视频 | 关键帧 + ASR | 视频理解 |

### 19.2 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 文件解析 | `parse.parse(path)` | 自动按扩展名选解析器 |
| 格式指定 | `parse.parse(path, format=...)` | 显式指定 |
| 多文件合并 | `parse.parse_many(paths)` | 多个文件合并 |
| 文本提取 | `parse.extract_text(path)` | 纯文本 |
| 表格提取 | `parse.extract_tables(path)` | 表格列表 |
| 图片提取 | `parse.extract_images(path)` | 图片列表 |
| 元数据 | `parse.metadata(path)` | 作者 / 创建时间 / 页数 |
| OCR | `parse.ocr(image_path)` | 图片转文本 |
| ASR | `parse.asr(audio_path)` | 音频转文本 |

### 19.3 创新设计

- **自动按扩展名选解析器**：无需显式指定
- **多格式统一接口**：PDF / Word / Excel 等走同一接口
- **表格 + 图片 + 文本三维度提取**：保留文档结构
- **流式解析大文件**：避免大文件爆内存
- **OCR + 视觉理解组合**：图片不仅提取文字，还理解含义
- **失败降级**：解析失败返回部分结果 + 错误说明

## 关键设计决策

### 决策 1：自动按扩展名
无需显式指定，简化调用。

### 决策 2：多格式统一接口
所有格式实现同一接口（`parse` / `extract_text` / `extract_tables`），LLM 无感。

### 决策 3：表格 + 图片 + 文本三维度
保留完整结构，不只提取文本。

### 决策 4：流式解析大文件
> 100MB 文件分块解析，避免 OOM。

### 决策 5：OCR + 视觉理解组合
图片不仅 OCR 文本，还用视觉模型理解含义（"这张图是说明 XX 的示意图"）。

### 决策 6：失败降级
解析失败返回部分结果，不抛异常。
