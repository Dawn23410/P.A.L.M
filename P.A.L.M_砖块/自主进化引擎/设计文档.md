# 砖块设计文档 - 16 evolution 砖（自进化与主动行为）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/evolution/`
> 定位：自进化、主动行为触发、用户画像分析

---

## 功能支持

evolution 砖负责 P.A.L.M 的"自学习"和"主动关心"能力。

### 16.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 主动行为 | `proactive.suggest()` | 主动给用户建议 / 提醒 |
| 主动问候 | `proactive.greet()` | 检测到用户开机 / 长时间未互动时主动问候 |
| 经验总结 | `evolution.summarize_experience()` | 从历史对话中总结经验 |
| 用户画像 | `evolution.update_user_profile()` | 从对话更新用户画像 |
| 模式识别 | `evolution.detect_patterns()` | 识别用户行为模式 |
| 知识蒸馏 | `evolution.distill_knowledge()` | 从记忆中提炼知识 |
| 个性化建议 | `evolution.personalized_suggest()` | 基于画像的个性化建议 |
| 自检改进 | `evolution.self_review()` | 评估自身表现并改进 |

### 16.2 主动行为触发

| 触发条件 | 行为 |
|---|---|
| 用户长时间未互动（> 1 天） | 主动问候 |
| 检测到用户日程事件（基于记忆） | 主动提醒 |
| 识别到新工具 / 新功能 | 推荐给用户 |
| 失败模式识别 | 主动承认 + 改进 |
| 节日 / 纪念日 | 主动祝福 |
| 用户画像变化 | 主动调整建议风格 |

### 16.3 经验总结

- **对话级总结**：单次对话的收获
- **用户级总结**：长期用户的偏好 / 习惯
- **全局总结**：跨用户的共性模式
- **失败模式总结**：哪些场景容易失败
- **成功模式总结**：哪些场景效果好

### 16.4 创新设计

- **主动 vs 被动并存**：用户可关闭主动行为
- **触发条件可配**：哪些场景触发主动行为可配置
- **经验总结 + 知识蒸馏**：把对话经验沉淀为知识
- **用户画像动态更新**：每次对话后增量更新
- **失败模式识别**：自动识别"哪类任务失败率高"
- **个性化建议**：基于画像生成

## 关键设计决策

### 决策 1：主动行为可关闭
主动行为是 P.A.L.M 的特色，但用户可关闭，尊重用户偏好。

### 决策 2：触发条件可配置
哪些场景触发主动行为可由用户配置（如"不要在工作时间发问候"）。

### 决策 3：经验总结 + 知识蒸馏双管齐下
单次经验 → 知识沉淀；用户级 → 全局模式。

### 决策 4：用户画像增量更新
每次对话后增量更新画像，避免全量重算。

### 决策 5：失败模式识别
自动检测"哪些任务失败率高"，驱动后续改进。

### 决策 6：自检改进循环
定期自检 + 改进策略，避免"自我感觉良好"。

## 性能与边界

- 主动行为检查间隔：1 小时
- 经验总结频率：每日 1 次
- 用户画像更新：每次对话后
- 主动行为最大频率：每天 3 次（避免打扰）
