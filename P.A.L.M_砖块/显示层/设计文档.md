# 砖块设计文档 - 25 display 砖（桌面显示层）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/display/`
> 定位：桌面组件、悬浮窗、桌面宠物

---

## 功能支持

display 砖在操作系统桌面层渲染 P.A.L.M 的可视化组件（宠物、状态、提醒、桌面小组件）。

### 25.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 创建组件 | `display.create(name, type, position)` | 新建桌面组件 |
| 列出组件 | `display.list_components()` | 当前所有组件 |
| 更新组件 | `display.update(name, data)` | 刷新数据 |
| 删除组件 | `display.remove(name)` | 移除 |
| 移动组件 | `display.move(name, x, y)` | 调整位置 |
| 调整大小 | `display.resize(name, w, h)` | 调整尺寸 |
| 切换主题 | `display.set_theme(theme)` | 切换配色 |
| 切换穿透 | `display.set_click_through(enabled)` | 切换点击穿透 |
| 置顶控制 | `display.set_always_on_top(enabled)` | 切换置顶 |
| 渲染 | `display.render(component, data)` | 渲染组件 |
| 截图 | `display.screenshot(region)` | 截取组件区域 |

### 25.2 组件类型

| 类型 | 用途 | 穿透模式 |
|---|---|---|
| 宠物 | 桌面宠物（动画） | full（完全不接收点击） |
| 状态栏 | 系统信息显示 | none（可交互） |
| 提醒窗 | 待办提醒 | none（可点击关闭） |
| 实时信息 | 时间 / 天气 / 笔记 | full |
| 浮窗 | 快捷操作 | none |
| 桌面小组件 | 笔记 / 日历 | full |
| 透明画布 | 装饰 | full |

### 25.3 形状约束

| 形状 | 规则 | 例子 |
|---|---|---|
| 矩形 | `border-radius ≤ 短边 20%` | 状态栏、笔记 |
| 圆形 | `border-radius: 50%` + 宽高相等 | 宠物头、状态指示 |
| 异形 | **禁止** | 不允许心形 / 星形等 |

### 25.4 创新设计

- **壁纸引擎 + 组件引擎合并**：display 砖同时承担两者能力
- **OS 级全有或全无穿透**：CSS 穿透无法真正实现，用 OS 级 API
- **形状严格约束**：矩形 / 圆形 二选一，禁止异形
- **组件大小贴合内容**：减少空白区域
- **可置顶 + 可穿透**：灵活控制
- **HWND_NOTOPMOST 简化方案**：避免 WorkerW 复杂重定向
- **WebView2 渲染**：组件实际为 HTML/CSS/JS

## 关键设计决策

### 决策 1：壁纸 + 组件合并
display 砖同时承担壁纸引擎和组件引擎，统一管理。

### 决策 2：OS 级全有或全无穿透
CSS 穿透无法真正实现（仍拦截下层点击），改用 OS 级 API（`WS_EX_TRANSPARENT`）。

### 决策 3：交互类 vs 观看类区分
纯观看类组件（宠物、状态栏）用 `full` 穿透；交互类（提醒窗、浮窗）用 `none`。

### 决策 4：形状严格约束
只允许矩形（圆角 ≤ 20%）和圆形（50% + 等宽高），禁止异形。**理由**：异形实现复杂且与穿透有冲突。

### 决策 5：组件大小贴合内容
组件高度 = 内容实际高度 + padding + gap，避免空白区域浪费。

### 决策 6：HWND_NOTOPMOST 简化
不实现 WorkerW 重定向（"桌面图标下方"），仅支持 HWND_NOTOPMOST（桌面级 / 置顶切换）。

### 决策 7：WebView2 渲染
组件实际为 HTML/CSS/JS，复用前端技术栈。

## 性能与边界

- 单桌面最多组件：20
- 组件刷新频率：1-10Hz
- 渲染延迟：< 16ms（60fps）
- 内存占用：~50MB（WebView2）
