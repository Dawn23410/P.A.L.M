# 砖块设计文档 - 10 settings 砖（配置管理）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/settings/`
> 定位：全局配置、用户偏好、运行时参数

---

## 功能支持

settings 砖统一管理所有可配置项（系统配置 / 用户偏好 / 砖块参数）。

### 10.1 配置分类

| 分类 | 用途 | 存储 | 示例 |
|---|---|---|---|
| `system` | 系统级配置 | JSON 文件 | 模型选择、路径、端口 |
| `user` | 用户偏好 | storage.kv | 主题、语言、API Key |
| `brick` | 砖块配置 | storage.kv | GUI 砖坐标采样间隔、memory 砖向量维度 |
| `runtime` | 运行时参数 | 内存 | 当前模型、最大迭代次数 |

### 10.2 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 读配置 | `settings.get(key, default)` | 路径式读取（`models.main`） |
| 写配置 | `settings.set(key, value)` | 立即持久化 |
| 删除配置 | `settings.delete(key)` | 恢复默认值 |
| 列出分类 | `settings.list(category)` | 返回某分类所有键 |
| 重载配置 | `settings.reload()` | 重新读文件 |
| 导出配置 | `settings.export()` | 导出为 JSON |
| 导入配置 | `settings.import(json)` | 批量覆盖 |
| 配置版本 | `settings.version()` | 配置文件版本号 |
| 监听变更 | `settings.subscribe(key, callback)` | 订阅某 key 变化 |

### 10.3 配置路径规范

- `system.models.main`：主模型名
- `system.models.flash`：平凡模型名
- `system.paths.data_dir`：数据目录
- `user.api_keys.openai`：OpenAI Key
- `user.theme`：UI 主题
- `brick.gui.coord_sample_interval`：坐标采样间隔
- `brick.memory.vector_dim`：向量维度
- `brick.safety.dangerous_commands`：危险命令黑名单

### 10.4 创新设计

- **路径式 key**：嵌套配置扁平化为 `"system.models.main"` 路径式字符串
- **分层存储**：系统配置写文件（只读），用户配置写 KV（可写）
- **运行时热重载**：修改配置无需重启进程
- **订阅回调**：砖块可订阅自身配置变化，自动重载
- **导出 / 导入**：用户配置可导出备份 / 跨设备同步
- **配置版本**：升级时支持自动迁移

## 关键设计决策

### 决策 1：路径式 key
嵌套配置扁平化（`system.models.main`），避免深层字典遍历。**好处**：读写一致；订阅变更简单。

### 决策 2：分层存储
系统配置只读文件；用户配置可写 KV。**好处**：用户改配置不影响系统配置；系统升级保留用户偏好。

### 决策 3：热重载
运行时改配置不需重启，订阅回调自动通知相关砖块。**好处**：调参不影响服务。

### 决策 4：pydantic 验证
所有配置通过 pydantic schema 验证，启动时校验必填项。**好处**：避免运行期才发现配置错误。

### 决策 5：版本迁移
配置文件带版本号，升级时自动迁移旧配置到新格式。**好处**：平滑升级。

## 性能与边界

- 配置读延迟：< 1ms（内存缓存）
- 配置写延迟：< 5ms（KV 落盘）
- 配置文件大小限制：1MB
- 路径深度限制：5 层
