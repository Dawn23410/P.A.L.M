# CosyVoice2 完整砖依赖（本机 RTX 5060 Laptop / Blackwell sm_120 验证通过）
#
# 重要：本砖是「完整砖」，cosyvoice 必须装进运行 P.A.L.M 的同一 Python 环境。
# 但依赖装配不能用一条 `pip install -r` 完成（会触发删除守卫 + 拉错 torch 构建），
# 真实配方见 plugins/cosyvoice/install.py（守卫安全、可复现），要点：
#
# 1) torch / torchaudio 必须 cu128（CUDA 12.8，含 sm_120 内核镜像）。
#    cu126 只编译到 sm_90，在 Blackwell 上推理报
#    `CUDA error: no kernel image is available for execution on the device`。
#    来源：https://download.pytorch.org/whl/cu128/  （PyPI/tuna 不便直装，用 curl+zipfile 解压）
# 2) cosyvoice / matcha 是 vendored 源码，拷贝进 site-packages（不走 PyPI 的 cosyvoice 包）。
# 3) 训练专用/无关传递依赖用纯 Python shim 顶替：lightning / gdown / wget / librosa /
#    soxr / pkg_resources / whisper.tokenizer。
# 4) 音频读写绕过 torchaudio→torchcodec（本机无 ffmpeg），用 soundfile（pysoundfile）。
#
# 下列为本机实测可用的「真实叶子包」精确版本（install.py 以 --no-deps 装入，避免冲突）：
hydra-core==1.3.2
pyarrow==25.0.1
soundfile==0.14.0
ruamel.yaml==0.17.40
# 以下由 torch / cosyvoice 传递拉入，已在环境中验证可用（无需手动装）：
# torch==2.11.0+cu128  torchaudio==2.11.0+cu128  numpy==2.5.2
# transformers==5.14.1  onnxruntime  modelscope==1.39.0
