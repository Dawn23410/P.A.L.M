# 砖块设计文档 - 11 roleplay 砖（角色扮演）

> 版本：v1.0（2026-08-13）
> 路径：`backend/app/bricks/roleplay/`
> 定位：角色卡片、人设台词、场景化对话

---

## 功能支持

roleplay 砖提供角色扮演能力，支持角色卡片、台词库、场景化对话。

### 11.1 核心能力

| 能力 | 入口 | 行为 |
|---|---|---|
| 加载角色卡片 | `roleplay.load(character_id)` | 读取 YAML / JSON 角色卡 |
| 列出角色 | `roleplay.list_all()` | 返回所有角色 |
| 角色信息 | `roleplay.get(character_id)` | 返回完整角色定义 |
| 创建角色 | `roleplay.create(card_data)` | 新建角色（用户自定义） |
| 编辑角色 | `roleplay.update(character_id, card_data)` | 修改 |
| 删除角色 | `roleplay.delete(character_id)` | 删除（保留系统默认） |
| 台词检索 | `roleplay.line_search(emotion, context)` | 按情绪 + 上下文找台词 |
| 场景化对话 | `roleplay.scene(scene_id)` | 加载场景 + 角色 |
| 角色状态 | `roleplay.state(character_id)` | 当前好感度、情绪、历史 |
| 多角色场景 | `roleplay.multi_role(character_ids)` | 多人对话 |

### 11.2 角色卡片结构

```yaml
character_id: shizuku
name: 雫
personality: 温柔、内敛、略带傲娇
appearance: 银发红瞳、身高 155
background: |
  ... 角色背景故事 ...
speech_style:
  first_person: 咱
  second_person: 你
  catchphrases: ["嗯", "是这样吗"]
  tone: 温柔、轻声
lines:  # 台词库，按情绪分类
  happy: [...]
  sad: [...]
  angry: [...]
scenes:  # 场景
  - id: first_meet
    background: ...
    initial_message: ...
relationships:  # 关系
  user: 陌生人
  ...
```

### 11.3 创新设计

- **角色卡片版本化**：每次编辑生成新版本，可回滚
- **台词按情绪索引**：根据检测到的用户情绪自动匹配台词
- **场景模板**：可定义剧情起点 + 推进规则
- **多角色协调**：支持多个角色同时在线（用户 + 多个 NPC）
- **声纹绑定**：角色可绑定声纹（声纹验证失败用角色语气回应拒绝）
- **可扩展 YAML / JSON**：用户可自己写角色卡片导入

## 关键设计决策

### 决策 1：YAML 角色卡片
用户友好；支持中文；可读性强。

### 决策 2：台词按情绪索引
情绪检测 → 台词库检索 → 拼接进 system prompt。

### 决策 3：场景模板
可定义"开场白 + 推进规则"，LLM 按场景规则生成。

### 决策 4：声纹绑定（30 秒静默期）
声纹验证失败用角色语气回应拒绝，然后进入 30 秒静默期（STT 继续监听但不处理）。

### 决策 5：声纹置信度三档
宽松 (0.35) / 默认 (0.45) / 严格 (0.55)，用户可调。

### 决策 6：角色状态持久化
好感度、关系进度、历史对话等存 storage 砖，跨会话延续。

## 性能与边界

- 单角色卡片大小：< 10KB
- 角色数量：默认 10 个系统角色 + 用户自定义（无上限）
- 台词库：每角色 < 200 条
- 场景数：每角色 < 20 个
