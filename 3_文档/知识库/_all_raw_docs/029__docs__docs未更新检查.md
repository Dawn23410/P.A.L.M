## 当前真实架构快照（更新参考）

- **插槽（总线）类型共 6 种**：`cpu` / `pcie` / `ram` / `sata` / `board` / `chip`。主板自身不是插槽。
- **主板当前加载的活跃砖共 23 块**（不含系统主板），按插槽分布：
  - cpu：Agent 框架
  - pcie：GUI 自动化、显示层、模型供应商、解析与结构化、Ollama 向导代理
  - ram：Token 用量、好感度引擎、对话缝合引擎、游戏生态、运行监控
  - sata：会话记录、记忆引擎
  - board：兜底防御、受控自我进化、定时任务引擎、对话、应用设置、文件处理、自主进化引擎、角色扮演引擎
  - chip：存储芯片+管理芯片、本机加解密
- **已禁用（N/O，暂不入主板）**：声卡（语音识别 / 语音合成 CosyVoice / 语音合成 GPT-SoVITS / 声纹识别 + 声卡分组自身）、网卡、沙箱执行。正本保留于 `archive/未授权禁用/`。
- **已归档（历史，非当前架构）**：裁决引擎（安全内核已拆分为 `palm_sdk.guardrail`，消费者改直连护栏）、离线模式、QwenTTS。
- **关键变更**：安全裁决内核由「裁决引擎砖」变为 `palm_sdk.guardrail`（5 档：死线/严格/宽松/AI/白名单），`/api/adjudicator/*` 端点已随砖移除；本机加解密 `bus_type` 由 `ram` 改为 `chip`；沙箱执行 `bus_type` 改为 `sata`；30 砖已通过 `palm_sdk` 运行基座解耦为独立可 import 单元（不再依赖 `backend/app` 单体）。
