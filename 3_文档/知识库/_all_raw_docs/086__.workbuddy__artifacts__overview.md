# P.A.L.M 操作台 UI 任务概述

## 任务
为 P.A.L.M 设计一个**操作界面**（非展示页），遵循主流软件审美（Linear / Vercel / Raycast / Notion 范式），从用户视角组织内容，并对排版进行可视化校验。

## 交付物
- **`frontend/palm-console.html`** —— 单文件可交互操作台原型，离线可用，深链接（`#tasks` 等）与 `?theme=dark` 支持。
- **`tools/shoot_html.py`** —— 基于 Edge 无头模式的可复用 HTML 截图工具（绝对路径输出 + 虚拟时间预算），用于排版可视化校验。

## 关键设计决策
1. **左图标栏 + 中工作区 + 右上下文栏**三栏布局，保留用户认可的框架。
2. **全部模块改为用户视角语言**（对话 / 任务与提醒 / 记忆 / 偏好 / 自动化 / 语音 / 隐私与安全 / 成长 / 设置），不再暴露 Boss/Worker、guardrail 5 档、执行器阶梯等内部术语。
3. **顶栏 ⌘K 命令栏**（搜索 + 下达指令），窄屏（≤720）退化为搜索图标。
4. **右侧栏上下文驱动**：每个页面切换时，根据 `asideCtx` 表动态替换中间内容块（标题+数据）和底部按钮（例如任务页 → "今天要做的"+ 3 条进行中；隐私页 → "最近一次拦截"+ 红色点）。
5. **对话页输入框钉底**：`.console-wrap` 改 flex 列、`.msgs` flex:1，符合聊天工具常规心智模型。

## 排版可视化校验流程
用自编截图工具（`tools/shoot_html.py`）把每个页面真实渲染成 PNG，再逐张肉眼检查，定位并修复了 4 个真实问题：
- 对话页输入浮在中间 → 改 flex 钉底
- 右侧栏在每页都一样 → 改为 `asideCtx` 动态切换
- 窄屏命令栏文字竖排 → 退化为图标
- 顶栏命令栏提示文字被截断 → 加宽至 380px 并缩短文案
