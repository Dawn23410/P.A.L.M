- 日期：2026-10-06
- 范围：`webui/pages/vendor-data.js` 中全部 17 家预设供应商的 `base`（默认端点）

## 二、MiniMax 专项（本次重点）

**官方域名格局（2026-10）**

| 用途 | 官方域名 |
|---|---|
| 国内文档站 | `platform.minimax.cn`（`platform.minimaxi.com` 归一到此） |
| 国内 API | `https://api.minimax.cn/v1` |
| 国际文档站 | `platform.minimax.io` |
| 国际 API | `https://api.minimax.io/v1` |
| 历史域名 | `api.minimax.chat`（**仍可用**，官方建议迁移） |

**官方原文佐证**（中文文档 `platform.minimax.cn/docs/api-reference/text-openai-api`）：

```bash
export OPENAI_BASE_URL=https://api.minimax.cn/v1
export OPENAI_API_KEY=${YOUR_API_KEY}
```

英文文档 `platform.minimax.io/docs/api-reference/text-openai-api` 对应：

```bash
export OPENAI_BASE_URL=https://api.minimax.io/v1
```

**实测**：`api.minimax.cn` / `api.minimaxi.com` / `api.minimax.chat` / `api.minimax.io` 四个域名均返回 `401`（路径有效、仅缺鉴权），说明旧域名 `.chat` 并未失效，属「官方建议迁移」而非「已停用」。

**判定**：配置 `https://api.minimax.cn/v1` 与国内官方文档逐字一致，**无需改动**。

> 备注：第三方博客（minimax-ai.chat）称国内为 `api.minimaxi.com`。该域名实测同样返回 401，属可用别名；但官方中文文档写的是 `api.minimax.cn`，以官方为准。

## 三、唯一修正：非线智能 NoneLinear

- **配置（错）**：`https://api.nonelinear.com/v1`
- **官方（对）**：`https://api.nonelinear.com.cn/v1`
- **证据一（官方文档）**：`docs.nonelinear.com/quickstart` 示例：
  ```python
  client = OpenAI(
      api_key="YOUR_API_KEY",
      base_url="https://api.nonelinear.com.cn/v1"
  )
  ```
- **证据二（实测）**：
  - `https://api.nonelinear.com/v1/chat/completions` → `000`（**域名不解析/连接失败**）
  - `https://api.nonelinear.com.cn/v1/chat/completions` → `401`（路径有效）
- **已修正**：`webui/pages/vendor-data.js:39`，`api.nonelinear.com` → `api.nonelinear.com.cn`
