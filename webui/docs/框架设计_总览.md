# 框架设计 · 总览（底层框架）

> **定位**：**底层框架** —— 只提供「**骨架 + 底座 + 契约**」，**不含任何业务 / 上层能力**。
> 上层建筑（具体 Agent、工具、UI、业务）建在它之上，且可替换。
> **一句话**：微内核 + 三位一体底座（安全 / 权限 / 日志）+ 契约驱动的插件。

---

## 三层（自下而上）

```
┌──────────────────────────────────────────────────────┐
│ L2 插件层   能力 = 插件（上层建筑在此构建，可替换）        │
├──────────────────────────────────────────────────────┤
│ L1 内核层   加载 · 卸载 · 依赖 · 生命周期                 │
│            服务容器（缺失归一 None）· 单一装配点 · 事件总线 │
├──────────────────────────────────────────────────────┤
│ L0 底座（不可绕过）  安全 · 权限 · 日志                    │
└──────────────────────────────────────────────────────┘
```

---

## 四件核心

| # | 核心 | 职责 |
|---|---|---|
| 1 | **微内核** | 只管 加载 / 卸载 / 依赖 / 生命周期；**不认识任何能力** |
| 2 | **契约** | 能力以接口定义；插件**只依赖契约，不依赖实现** |
| 3 | **底座** | 安全 / 权限 / 日志 —— 下沉最底、**不可绕过** |
| 4 | **插件模型** | 能力 = 插件（平级）；**单一装配点**注册 |

---

## 三大机制

1. **握手鉴权**：主密钥随框架初始化随机生成（仅内存）→ 模块加载读 MK + 自生成随机盐 → 对称会话密钥 `SK = KDF(MK, S)` → 请求带加密信息头 → **识别一致才接收**。
2. **模块沙箱**：每模块 = 独立作用域 + 专属能力 `ctx` + 故障边界；**默认进程内（开销 ≈ 0）**，重模块可选子进程。
3. **热插拔**：插件登记的副作用**可逆**（卸载即回滚）。

---

## 三条铁律

1. **门面收敛**：L2 的一切敏感动作（出网 / 命令 / 敏感路径 / 敏感能力 / 写 / 模块间请求）**必经 L0**。
2. **fail-closed**：默认拒绝；放行必须显式。
3. **append-only 可观测**：任何决策（放行 / 拒绝 / 降级 / 回滚）写进只追加事件流。

---

## 高可用（只留 3 条）

1. **缺失归一降级**：组件缺失 → `None`，业务判空，不崩。
2. **可逆回滚**：热插拔卸载即回滚副作用。
3. **可重试**：限流 / 超时等可重试错误自动重试。

---

## 明确不做（避免过度工程 / 上层建筑）

| 不做 | 原因 |
|---|---|
| 多档裁决引擎、规则热重载 | 上层治理，按需再加 |
| 纵深沙箱（AST+网络拦截+蜜罐） | 过度设计；底层只要"稍微防" |
| 保险库、看门狗、分级启动 | 上层运维，不属于骨架 |
| 双总线、工具执行四件套 | 过度抽象 |
| 沙箱多级隔离（受限执行 / 远端 tcp·ws） | 过度设计；底层只留「进程内 + 可选子进程」 |
| 任何具体业务（记忆 / 情感 / 角色 / GUI …） | 属上层建筑 |

---

## 一句话记忆

**安全 = 能不能做　　权限 = 准不准做　　日志 = 做了什么**
—— 三者同层咬合，构成不可绕过的底座。
