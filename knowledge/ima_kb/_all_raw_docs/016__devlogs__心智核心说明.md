# 心智核心（MentalCore）使用说明

> AI 陪伴聊天核心：有性格、有记忆、有情绪、有好感度的对话引擎。
> 纯聊天文本通道（限死）：不做工具调用、不开深度思考，一律非推理模型、首字优先。

---

## 一、快速开始（小白三步）

**双击启动脚本**即可（副本已含全部依赖与语料，无需任何安装）：

```
桌面\mentalcore\启动梦瑶.bat
```

首次运行会自动弹出**中文配置向导**，二选一：

| 选项 | 说明 |
|---|---|
| `1` 离线体验 | 无需任何账号与密钥，用内置 619 条梦瑶手写语料聊天（推荐先试玩） |
| `2` 在线聊天 | 填写服务地址 / 模型 / 密钥（详见「四、在线配置」） |

配置齐全后直接进入**控制台**，再次运行不再打扰。

---

## 二、控制台（OpenClaw 风格）

启动后先呈现状态面板 + 编号菜单：

```
运行模式   mock（离线，零 API 调用）
模型       mock-pro
服务地址   （未设置）
加密落盘   SM4 已启用
语义记忆   可用
关系状态   初识（好感 0.2 / 羁绊 0.00）
对话记忆   2 条

操作
1  开始聊天
2  重新配置（向导）
3  离线自检（selftest）
4  数据管理（查看记忆/好感度）
0  退出
```

**全局约定：任意输入 `0` = 退回上一步**（顶层菜单 0 = 退出）。聊天结束后自动回到控制台，可继续操作或退出。

---

## 三、聊天界面

控制台选 `1` 进入聊天：

- **↑ / ↓** 翻历史输入；**回车** 提交；**Tab** 补全 `/` 命令
- 梦瑶回复**流式逐字输出**，完成后附「首字耗时」与「外发字段」
- 输入 `/exit` 返回控制台（聊天里 `0` 是对话内容，不能用于退出）

### 聊天内命令

| 命令 | 作用 |
|---|---|
| `/model` | 查看当前模型信息 |
| `/manifest` | 查看本轮注入清单（人格/记忆/情感/织语/律动） |
| `/config` | 查看运行配置（模式/地址/模型/密钥脱敏/加密/语义记忆） |
| `/code <五位码或意图>` | 执行控制码（见下） |
| `/receive <内容>` | 外部注入一段上下文 |
| `/persona <新描述>` | 改人设并清空记录与向量（防污染） |
| `/help` | 帮助 |
| `/exit` | 返回控制台 |

### 五位控制码

| 控制码 | 含义 |
|---|---|
| `10000` | 查询对话记录 |
| `11000` | 查询向量归档 |
| `10100` | 清空对话记录 |
| `11100` | 清空向量归档 |
| `13000` | 加密状态（SM4 国密） |

## 四、在线配置

控制台选 `2` → 选 `2 在线聊天`，按提示填写：

1. **AI 服务地址**：形如 `https://api.deepseek.com`（OpenAI 兼容端点，可从服务商文档复制）
2. **API 密钥**：粘贴以 `sk-` 开头的密钥
3. **自动检测模型**：自动拉取该端点模型列表，**↑↓ 选择 + 回车确认**（输入 `0` 返回上一步）

自动兜底：部分端点不提供模型列表 → 自动改用 chat 接口探测，探测成功则**手动输入模型名**；连接失败弹菜单（重填密钥 / 重填地址 / 返回）。

配置统一写入 `.env`（见「六、配置」），代码与脚本**零内置**地址与密钥。

> 建议使用非推理模型（首字更快、不开深度思考）。实测参考：DeepSeek 官方 `deepseek-v4-flash`（关推理）首字约 0.9s。

## 五、运行模式

| 模式 | 说明 |
|---|---|
| `mock` | 离线零成本。MockLLM 在 **619 条梦瑶手写语料**（`palm/services/chat/corpus/mengyao_hq_part*.jsonl`）中做相似度检索，找到最像的问题返回对应手写回复（`[动作]（神态）<内心>正文` 织语格式、猫娘人设）；相似度不足或语料缺失时回退模板兜底 |
| `live` | 真实 LLM。PalmLLM 桥接 palm 模型层走 OpenAI 兼容端点，异步流式经线程桥接逐字产出 |

切换方式：`/config` 查看当前模式；改 `.env` 的 `MENTALCORE_MODE=mock/live`，或命令行加 `--mock`。

## 六、配置（.env）

所有配置项集中在 `.env`（副本位于 `桌面\mentalcore\.env`，已被 gitignore 保护，不入库）：

| 变量 | 说明 |
|---|---|
| `MENTALCORE_MODE` | `mock`（默认，离线零 API）/ `live` |
| `MENTALCORE_BASE_URL` | OpenAI 兼容端点（live 必填） |
| `MENTALCORE_MODEL` | 模型名（live 必填，非推理模型） |
| `MENTALCORE_API_KEY` | API 密钥（仅本地） |

其他可选：`MENTALCORE_TEMPERATURE` / `MENTALCORE_MAX_TOKENS` / `MENTALCORE_EMOTION_VIA_LLM` / `MENTALCORE_LOG_LEVEL` 等，均以 `MENTALCORE_` 前缀覆盖。

安全默认：无配置时自动走 `mock`，绝不因缺配置崩溃或产生 API 费用。

## 七、架构

```
六面（prompt 模块）  人格 / 记忆 / 情感 / 织语 / 律动 / 储存
两个中间件          动态注入（固定上·动态下·清单留痕）/ 回复拆分（好感度消费·其余外发）
模型层（纯文本通道） PalmLLM（live，桥接 palm provider）/ MockLLM（离线，语料检索）
```

- **情绪识别**放后台线程，不阻塞首字
- **好感度吝啬制**：日常 Δ=0（小数制，如 +0.1/-0.3），仅关系质变轮给幅度；base/bond/dynamics 实时显示在控制台与侧栏
- **数据区协议**：模型回复末尾附 `||DATA||{"affinity_delta": ...}||END||`，拆分中间件消费好感度变化，**不外发到用户可见正文**（协议遵守率 100%）

## 八、持久化（重启不丢）

| 数据 | 存储 | 说明 |
|---|---|---|
| 对话记录 | `mentalcore_data/conversations/conversations.dat` | SM4 国密加密 |
| 语义记忆 | `mentalcore_data/vector_memory/` | chromadb 向量（1024 维 bge-m3 本地 ONNX） |
| 好感度 | `mentalcore_data/conversations/affinity.dat` | SM4 加密（base/bond/dynamics 跨重启恢复） |
| 主密钥 | `mentalcore_data/.master_key` | 首次运行自动生成 |

以上全部自动落盘，关闭重启后对话、记忆、好感度完整恢复。

## 九、目录结构（桌面自包含副本）

```
桌面\mentalcore\
├── mentalcore\            心智核心源码（六面+中间件+控制码+CLI+控制台）
├── palm\                  依赖库（含语料 corpus\、bge-m3 ONNX 权重 weights\）
├── pyenv\                 精简虚拟环境（httpx/onnxruntime/tokenizers/chromadb/gmssl/textual/prompt_toolkit 等）
├── .env                   本地配置（端点/模型/密钥）
├── 启动梦瑶.bat            一键启动（首次自动向导）
└── README.md              简版说明
```

完整自包含：脱离 Ollama（向量走本地 ONNX 1024 维）、LLM 的 Ollama 仅保留 OpenAI 兼容接口、语料内置——拷贝整个文件夹即可在任何 Windows 机器上运行。

## 十、自检与开发

```bash
# 离线自检（强制 mock，零 API 调用，固定断言）
python -m mentalcore.cli --selftest

# 全量测试（17 项：编排/加密/注入/拆分/传输/向量记忆）
pytest
```

自检覆盖：情绪识别、注入清单（含记忆面）、五位控制码、改人设防污染清档、SM4 加密状态，全部 PASSED 后输出 `=== selftest PASSED ===`。
