# 心智魔方（MentalCore）生产环境就绪度评估

> 评估日期：2026-08-19 · 评估对象：mentalcore（梦瑶聊天核心 + 好感度系统 + 语义记忆）
> 依据：代码审查 + 100 次实测基准（bench_100_raw.json）+ 环境核查

## 结论摘要

| 场景 | 判定 | 一句话理由 |
|---|---|---|
| **本地单用户生产**（个人自部署、桌面运行） | ✅ **基本就绪**（有条件） | 稳定跑通 100 轮、加密对话、全链路降级韧性；但需接受延迟波动与向量明文 |
| **多用户 / 对外服务**（SaaS / API 化） | ❌ **未就绪** | 无并发与鉴权设计、核心无重试、向量明文、依赖单点外部服务、无 SLA |

## 二、部分就绪项（可用但有缺口）

| 项 | 现状 | 缺口 |
|---|---|---|
| **延迟** | TTFB 中位 5.6s（低谷 1.3-3s）；本地链路已最优（连接复用/真流式/情绪异步/固定事件循环） | P95 32s、最大 80s——公共免费端点服务端波动不可控；体验 SLA 无法承诺 |
| **错误恢复** | CLI/采集脚本层有 429 退避重试 | **MentalCore API 本身无重试**：调用方（生产 API 封装）必须自己实现 |
| **数据持久化** | 对话加密 + 向量持久化（chroma.sqlite3） | **向量记忆明文落盘**（见阻断项 1） |
| **可观测性** | logging 有（logging_setup） | 无指标/健康检查/延迟直方图/链路 trace |

## 三、未就绪 / 阻断项（上生产前必须处理）

1. **向量记忆明文落盘（P0 隐私阻断）**
   `VectorMemory.add` 把对话原文直接写入 `chroma.sqlite3`（明文，仅 `content_hash` 防重）。对话记录加密了，**向量库却是明文的**——本机其他进程/备份可读全部对话内容。与"SM4 加密对话"的安全承诺不一致。
   → 修复方向：向量文档字段加密（复用 SM4 原语，检索前解密/或存哈希检索+密文文档）；或明示"向量明文"并落到隐私说明。

2. **核心 API 无重试/幂等（P1）**
   `core.stream_message` 遇 429/5xx 直接抛 RuntimeError，由调用方兜底。生产封装层需：指数退避重试（429/连接错）、超时配置、请求幂等（重复投递不双写记录）。

3. **无鉴权与多用户隔离（P1，若对外）**
   单实例单用户设计（全局好感度/历史/向量库），无会话鉴权、无租户隔离。多用户需按会话划分 storage/chroma/好感度状态。

4. **外部单点依赖（P1）**
   运行强依赖：NoneLinear 免费端点（无 SLA、随时限流/下线）+ 本机 Ollama（嵌入）。任一下线 → 降级（对话降级为仅近期记忆 / 模型调用失败）。
   → 需：端点可配置多路故障切换；Ollama 缺失时嵌入降级已存在（但语义记忆失效）。

5. **监控与告警（P2）**
   无 /healthz、无延迟/错误率指标。生产需：首字延迟直方图、数据区遵守率、错误率、Ollama/端点连通性探针。

6. **打包分发（P2）**
   palm 为同仓库兄弟目录（非 pip 依赖），正式分发需一并打包；桌面副本靠 PYTHONPATH 注入。

## 四、生产场景判定

- **个人自部署（当前形态）**：可用。桌面 `梦瑶聊天.bat` 即生产形态；建议补充：定期备份 `mentalcore_data/`、接受延迟波动、知晓向量明文。
- **内部单用户服务**（如个人 API/网页包装）：**有条件可用**——需补：core 层重试封装、/healthz、Ollama 与端点连通性守护；向量明文可在内部网络接受。
- **对外多用户 SaaS**：**不建议**——按第三节 2/3/4/5 补齐（尤其向量加密+鉴权+重试+SLA 端点）后方可评估。

## 五、就绪路线图（按优先级）

| 优先级 | 事项 | 预估投入 |
|---|---|---|
| P0 | 向量记忆加密（复用 SM4 原语，密文文档 + 哈希检索） | 中 |
| P1 | core 层自动重试（429/5xx 退避）+ 超时参数 | 小 |
| P1 | 健康检查 /healthz + 延迟与错误指标（首字直方图/遵守率/错误率） | 小 |
| P1 | 端点故障切换（多 base_url 列表） | 小 |
| P2 | 会话鉴权与多用户隔离（若对外） | 大 |
| P2 | 商业端点或本地模型接入（SLA 与延迟承诺） | 中 |
| P3 | 打包分发（palm 依赖并入 wheel）+ Docker | 中 |

---

**总体评价**：作为**个人本地生产的"活体伴侣内核"**，心智魔方已经站得住——功能完整、稳定性经过 100 轮实测、数据有加密有降级；但**作为对外服务还差三道硬门槛**：向量明文、核心无重试、外部单点依赖。若目标是"自己能长期用"，现在就可以；若目标是"给别人用"，先做 P0+P1 四件事。
