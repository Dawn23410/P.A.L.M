# 砖块最小接口一览（小白版）

> 把 P.A.L.M 想成一台电脑：**主板**把所有「砖块」插在一起，每块砖就是一个独立的功能模块。
> 下面只讲两件事——**它叫什么**、**它干什么**，不聊技术细节。

---

## 一、对话与大脑

- **对话**：你打字和助手聊天的入口，负责把你的话送出去、把回答一句句流式返回。
- **Agent 框架**：助手的「大脑调度器」。会先列计划、一步步执行、失败了自动换办法，还能调用各种工具。
- **模型供应商**：负责对接大模型——发现当前有哪些可用模型，并把回答一段段生成出来。

## 二、角色与陪伴

- **角色扮演引擎**：让助手变成某个人设（比如猫娘），并一直维持它的语气和性格。
- **好感度引擎**：记录助手对你的好感变化（亲近 / 互动 / 羁绊），像养成游戏里的数值。
- **对话缝合引擎**：让角色对话更自然——检索合适的人设语料并缝进回答里（默认离线，不联网）。

## 三、记忆与记录

- **记忆引擎**：助手的长期记忆。记住你说过的重要事，能语义检索、自动压缩长对话。
- **会话记录**：把每次聊天存档，关掉软件再打开还能接着聊。

## 四、耳朵与嘴巴（语音）

- **语音识别**：把你说的话（麦克风）转成文字，助手就能「听懂」你说话。
- **语音合成（GPT-SoVITS）**：把文字实时读成语音，让助手开口说话（本地播报）。
- **语音合成（CosyVoice）**：用「描述 + 参考音频」造出一种新音色，做声音素材给上面的合成用。

## 五、文件与存储

- **文件处理**：接收你上传的文件，做权限检查后让助手能读取里面的内容。
- **解析与结构化**：识别文档 / 图片，提取成统一的结构化内容（含图片里的文字识别）。
- **存储芯片 + 管理芯片**：系统的「硬盘」。负责加密保存数据、管理容量配额、备份保险库、健康监测。
- **本机加解密**：用国密算法把数据锁起来，钥匙绑在你这台电脑上，更安全。

## 六、安全与隐私

- **裁决引擎**：安全审核员。用规则检查 AI 想做的动作，防止它乱删文件、搞坏系统。
- **沙箱执行**：让 AI 写的代码在隔离环境里跑，不伤到本机；删除走回收站、危险操作被拦下。
- **兜底防御**：安全网。AI 要删文件前先自动备份，出问题能找回；还有系统还原点汇总。
- **离线模式**：一刀切断外网，只许连本机服务（比如本地模型），断网也能用。

## 七、自动化与界面

- **GUI 自动化**：让助手帮你操作电脑界面（点按钮、填表等），能看懂屏幕并自动执行。
- **显示层**：负责把壁纸、桌面悬浮小部件等画面渲染出来。
- **Ollama 向导代理**：帮你在本机装模型、下载模型、部署模型的引导助手。

## 八、设置与记账

- **应用设置**：保存和读取软件设置（外观、额度等）。
- **Token 用量**：记账员。记录每次对话花了多少额度，超额就拦住。

## 九、后台与进化

- **定时任务引擎**：定时提醒 / 定时触发任务，到时间点你一下。
- **自主进化引擎**：后台悄悄学习你的习惯、每天给你偏好简报、空闲时自我优化。
- **受控自我进化**：AI 提改进建议（注册工具 / 沉淀技能），经人审核后才生效，可控不失控。

## 十、游戏化与监控

- **游戏生态**：把使用变成游戏——经验等级、每日任务、星砂货币、商城道具。
- **运行监控**：看着游戏是否在跑、当前是「高性能」还是「省电」模式。

## 十一、底座

- **主板**：把所有砖块插在一起的底盘。提供插槽 / 注册表、事件广播、开机自检，是整套系统的骨架。
