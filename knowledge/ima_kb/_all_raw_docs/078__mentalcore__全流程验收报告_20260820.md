## 验收过程中发现并修复的缺陷（5 个真 bug + 3 个加固）

| # | 类型 | 问题 | 修复 |
|---|---|---|---|
| 1 | 崩溃 bug | `30300` 传非数值（base=abc）→ `float()` 抛 ValueError 直接炸 | try/except 优雅拒绝「base 必须是数值」 |
| 2 | 崩溃 bug | Windows 下沙箱 subprocess 输出 GBK，按 UTF-8 解直接炸线程 | 字节解码容错（errors=replace 双编码回退） |
| 3 | 健壮性 | `_execute_tool` 不捕获工具 fn 异常——单次工具失败（如路径越权）直接炸掉整个 Worker 任务 | 异常转观测文本回灌，模型可纠偏或收尾 |
| 4 | 健壮性 | `ExoLLM.complete` 无重试——端点一次断连任务即失败 | 3 次递增重试（1s/2s/4s） |
| 5 | 接线 bug | ask 桥闭包固化：装配时把 `ask_bridge=None` 固化进工具，`make_broker` 接线不生效 | 改为模块级运行时引用 `_ask_ref`，接线时同步更新 |
| 6 | 接线 bug | PlanEngine 漏导入 `STEP_PENDING` → use_planning 路径 NameError | 补导入 |
| 7 | 加固 | Worker 任务异常静默死线程 | 异常也回传 Boss 失败信息 |
| 8 | 加固 | Worker 提示历史无限增长 | 摘要式压缩（keep_recent=6，实测省 15% 成本） |

## 用户视角评价

### ✅ 立即可用（mock 全链路 + live 已实测）
1. **心智魔方**：五面人格、好感度系统、18+ 控制码、SM4 加密、防污染清档、重启恢复——全部实测可用；
2. **外骨骼 Worker**：19 工具、6 小魔方（含安全总闸）、原生 function calling、自主规划、干预队列、ask 中转、轨迹审计——全部实测可用；
3. **双魔方接线**：委派→执行→回传→Boss 摘要注入，端到端闭环实测通过。

### ⚠️ 上线前需注意（非阻塞）
1. **B2 协议遵从**：GLM-4.5-Flash-nothink 不输出 `||DATA||` 数据区 → 好感度变化收不到模型侧增量。属模型行为依赖，建议在提示中强化数据区要求或做降级兜底；
2. **端点稳定性**：该免费端点偶发断连/挂起（Worker 重试已覆盖断连；无限挂起暂无超时保护，建议生产端换稳定端点）；
3. **模型工具选择**：真实模型在「单一工具任务」上可能跑偏（如 ask 任务先调文件工具），建议提示词强化「严格按任务描述调用工具」；
4. **ask 阻塞时长**：60s 等待窗口，宿主需及时应答，否则 Worker 收到超时提示继续。
