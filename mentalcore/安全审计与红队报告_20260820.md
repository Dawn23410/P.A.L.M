## 四、残余风险与建议（环境/架构级，非本次可改）

1. **【高】API key 明文在桌面**：建议将 `可用API.json` 移入受保护目录或删除明文副本，改用环境变量/凭据管理器；限制文件 ACL（仅当前用户）。
2. **【中】沙箱非权限隔离（架构级）**：Windows 下 `run_shell` 以当前用户全权限执行，目录隔离 ≠ 权限隔离。加固方向：以受限账户运行 Worker 进程、或用 Windows AppContainer；当前依赖黑名单+敏感路径+权限闸门三层纵深。
3. **【低】`_INJECTION_RE` 是黑名单式清洗**：属纵深防御而非完整防注入；LLM 注入根治需「输出隔离 + 工具调用白名单 + 确认门」组合（已具备后两者）。
4. **【低】DNS rebinding**：SSRF 校验基于解析时 IP，无法防 rebinding；建议生产环境 web_fetch 走代理/固定出口。
5. **【提示】`.master_key` 权限**：建议 ACL 收紧为仅当前用户（Windows icacls）。
