## 一、结论先行

| 口径 | v2.0（733 簇） | **本版（2707 簇）** | 变化 |
|---|---|---|---|

## 二、性能占用实测（真实混合负载，非域内快路径）

### 2.1 内存

| 阶段 | RSS | 说明 |
|---|---|---|
| Python 基线 | 19 MB | |
| 引擎启动完成 | 1872 MB | bge-m3 int8 (570MB) + reranker v2-m3 int8 (880MB) + Randeng-T5-77M + 2707×1024 索引 |
| 首次响应后 | 2700 MB | +828MB 为 ONNX 内存 arena 惰性增长 |
| **峰值稳态** | **2725 MB** | 占 15.7GB 物理内存的 **16.9%** |
| 线程 | 65 | 3 个 ONNX session 各自的 intra-op 线程池 |

### 2.2 延迟（关键：分两种路径，不许混）

| 路径 | median | p90 | max | 瓶颈 |
|---|---|---|---|---|
| **单轮快路径**（coherence 未触发） | **15.9 ms** | **18.5 ms** | 32 ms | embed ~15ms 为主体，检索点积 ~1ms |
| **多轮**（coherence 重排触发） | 34 ms | 213 ms | 307 ms | cross-encoder 对 8 候选各 ~25ms |
| reranker 仲裁 | 触发时 64ms/对，本负载 0 触发（快带直接接受） | | | |

**归因消融**（同负载）：关 coherence → p90 213ms 立降 18.5ms；关 reranker 无变化。**p99 尖峰 100% 来自 coherence 重排**，它是多轮质量的代价，不是 bug。

### 2.3 启动

boot 3.6s（三模型加载 + 索引）+ 首次响应 1.5s（embed session 实例化）= **冷启动 ~5.1s，一次性**。

### 2.4 算力

全 CPU（零 GPU），ONNX 多核并行（CPU 时间远超 wall time）。对比锚点：本地 7B fp16 需 ~14GB 显存、int4 需 ~4GB（RTX 5060 8GB 可跑），典型首 token 延迟数百 ms——**以下为公开典型值，非本机实测**。

## 四、等效 B 推定推理链

锚点表（v1.0 建立，通用模型"随口一句能聊"可用率）：0.5B~20% / 1B~35% / 1.5B~45% / 3B~65% / **7B~82% / 14B~90%**。

```
加权 = 0.55 × T3可用(94.6%) + 0.45 × T4可用(87.9%) = 91.6%
```

91.6% 已触及 14B 锚点（~90%）。但**必须披露三点**：

1. **锚点表在 90% 以上饱和**——14B 与 32B/70B 在该指标上不可区分，只能说"≥14B 档下沿"，不能说"超过 14B"。
2. **失败模式结构性优于 LLM**：引擎 FAIL = 诚实兜底（0 幻觉），真 14B 的失败是自信胡编。同等可用率下体验不可直接划等号——这是加分项。
3. **同类泄露风险**：part17–50 补洞与 T3/T4 测试集同属日常话题域，2-gram 过滤只挡字面重合，挡不住主题邻接。真实分布的可用率应低于 91.6%，**保守区间 85%–92%**。

### 与真实模型的场景级对比

| 维度 | 本引擎（全 CPU） | 7B 本地 int4（典型值） | 云端 14B+ |
|---|---|---|---|
| 域内闲聊贴题+人格 | ≈14B 档 | ~82% 可用 | ~90%+ 可用 |
| 幻觉 | **0**（不生成） | 有 | 低 |
| 人格一致性 | **100%**（语料即人格） | 漂移 | 提示词维持 |
| 出域知识 | 兜底（零生成） | 能答但小模型常错 | 强 |
| 延迟 | 16ms（多轮 34ms） | 数百 ms/首token | 网络+数百 ms |
| 资源 | 2.7GB RAM，0 GPU | ~4GB 显存 | 零本地 |
| 多样性 | 域内池轮换，distinct 1.0 | 高 | 高 |

**一句话定位：这是"开销换体验"的极致——1/3 秒内、零 GPU、2.7GB 内存，把覆盖到的 2700 簇日常闲聊做到 14B 档且零幻觉；代价是出域即交棒（诚实兜底），以及长尾覆盖永远在追。**

## 五、没治好的问题

1. 4 个假阳性（洗澡→洗手、你家在哪→在吗等）——守卫模式可治，属增量工作，未在本版处理。
2. T5 仅 7 轮，长程一致性（>20 轮）未充分测试。
3. coherence 重排 p90 213ms——多轮长对话的体验代价，可做候选数 8→4 的截断优化，未做。
4. 锚点表本身是主观标定（非真机 A/B），本版未部署真 14B 做 same-hardware 对照。
