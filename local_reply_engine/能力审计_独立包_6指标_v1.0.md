## 七、方案 A 落地记录（同源引擎全部打包，2026-09-06）

### 7.1 打包结构（独立包最终形态）
```

├── __init__.py          # 导出：风格子系统 + 引擎子系统（StitchEngine/HybridRetriever/Hub/...）
├── persona_card.py      # 角色卡（梦瑶默认）
├── simulator.py         # LocalChatSimulator：wrap StitchEngine，reply()/diagnose()/build_prompt()
├── transport.py
├── faces/               # 7 面风格子系统（base/persona/memory/emotion/weave/rhythm/storage）
├── middleware/          # inject(PromptAssembler) + split(ReplySplitter)
└── engine/              # ★ 新增：同源离线聊天引擎（移植自 P.A.L.M/palm/services/chat/）
    ├── __init__.py      # 导出 StitchEngine/HybridRetriever/Hub/Sentiment/Rewriter/parse_reply/...
    ├── core.py          # HybridRetriever + parse_reply + load_persona_bank + EXPRESSION_LIB
    ├── engine.py        # StitchEngine（检索→桥接→调味→改写→回调）
    ├── hub.py           # Embedder(离线哈希) + Sentiment(词典) + Rewriter(模板) + Hub
```

### 7.2 关键改造点
- `hub.py` 模型目录改为包内自包含：`_BGE_M3_DIR = engine/models/weights`（不再指向 P.A.L.M 外部 `domain/memory/`），确保独立包不依赖外层项目。
- `simulator.py` 重构：`LocalChatSimulator.__init__` 初始化 `StitchEngine()`（自动装载 2837 段语料）；`reply()` 调用 `engine.respond()`，并把历史 `(user,reply)` 元组转为"历史回复字符串列表"传给引擎 `_callback`（修复一处 `tuple in str` 类型 bug）。
- 风格子系统（faces/middleware）保留为可选增强层（build_prompt() 仍可用，证明 weave 子系统未被移除）。
