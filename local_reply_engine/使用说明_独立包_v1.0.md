# 梦瑶本地对话引擎 · 独立包使用说明 v1.0

> 更新：2026-09-07 ｜ 自包含，不依赖 P.A.L.M 等外部项目

## 一、这是什么

本地检索缝合型猫娘对话引擎（梦瑶人格），三档可切，零 GPU、零网络（天气工具除外）、零幻觉。

## 二、三档对比（2026-09-07 实测，tier_compare_v1.0.json）

| | 满血档 `--full` | 性能档 `--balanced` | 节省档 `--lite` |
|---|---|---|---|
| 检索后端 | bge-m3 语义（1024 维） | bge-small 语义（512 维） | 纯 mock lexical |
| reranker / 连贯重排 | 全开 | 关 | 关 |
| 内存（稳态，多轮后） | 2717 MB | **161 MB** | **32 MB** |
| 单轮延迟 median | 17 ms | **2.2 ms** | **0.2 ms**（p95 ~4ms） |
| 多轮延迟 median | 182 ms（重排代价） | 54 ms | 0.3 ms（每轮独立检索） |
| T2 改写命中 | 30/30 | 28/30 | 22/30 |
| T3 高频句命中 | 55/56 | 52/56 | 50/56 |
| T4 未见句命中 | **52/56** | 34/56 | 16/56 |
| 聊天等效（149 句盲评，三档等效评测 v1.0） | **≥14B** | **≈5B** | **≈2B** |
| 启动耗时 | 3.8 s | 0.2 s | 0.03 s |

选型：日常陪聊选满血；常驻后台/低配机选性能（短句体验几乎无损，长句泛化缩水）；嵌入其他项目/极致轻量选节省。

> 注：lite 档单轮延迟经本包倒排索引优化（2026-09-07 追加），由早期 ~18ms 降至 sub-ms（median ~0.2ms、p95 ~4ms），且换上 2 万条语料热替换后无大幅衰退（详见《接口文档_模型API_v1.1》/reload 节）。

## 三、使用

### 方式一：双击启动（推荐）

`梦瑶对话.bat` → 输入 1/2/3 选档位 → 进入对话。

### 方式二：命令行

```bash
python run_chat.py              # 满血档
python run_chat.py --balanced   # 性能档
python run_chat.py --lite       # 节省档
```

对话内命令：`/stats` 上一轮状态 | `/reset` 清空记忆 | `/exit` 退出。

### 方式三：代码调用

```python
from local_reply.engine.engine import StitchEngine
eng = StitchEngine(tier="balanced")          # "full" | "balanced" | "lite"
r = eng.respond("我好累", [])                 # history: [(user, reply), ...]
print(r["reply"], r["confidence"])
```

## 四、目录结构

```
local_reply_engine/
├── run_chat.py                  # ollama 式对话入口（三档）
├── 梦瑶对话.bat                  # 双击启动（菜单选档）
├── local_reply/engine/
│   ├── engine.py                # 主引擎（tier 参数）
│   ├── embed.py                 # 嵌入层（m3/small 可切，env PALM_EMBED_MODEL）
│   ├── reranker.py              # v2-m3 cross-encoder（仅满血档加载）
│   ├── corpus/                  # 2837 条梦瑶人格语料（50 个 part 文件）
│   ├── data/                    # 向量索引缓存（按模型命名）
│   └── models/weights/          # bge_m3.onnx 570MB + bge_small.onnx 24MB + tokenizers
├── run_chat.py / 梦瑶对话.bat
└── *.md                         # 基准/对比/研究报告
```
