## 一、实测结果（真实数据，非估计）

### 1.1 回复延迟（latency）
| 指标 | 数值 |
|------|------|
| 冷启动（引擎初始化 + 619 段语料装载 + BM25/IDF 建索引） | **114.8 ms** |
| 样本数 | 266 次 respond() |
| 均值 | **2.15 ms/回复** |
| p50 | 2.03 ms |
| p95 | 3.37 ms |
| p99 | 3.68 ms |
| 最大 | 3.80 ms |

> 结论：纯 Python 标准库检索缝合，**单次回复 < 4ms**，与"推理"无关，属查表级延迟。

### 1.2 回复匹配度（match / 答为所问）
| 指标 | 数值 | 说明 |
|------|------|------|
| 域内测试集规模 | 28 条（覆盖问候/陪伴/情绪/日常/道别/亲昵） | 预期应命中 |
| recognized_rate（引擎判定为命中） | **0.893** | 25/28 域内问题被自信召回 |
| recall_real_rate（top1 分 ≥ 0.02） | **0.893** | 同上 |
| avg_top1_score | 14.0 | BM25+字 n-gram 混合分 |

> 结论：**域内命中率 89%**，答为所问在窄域内成立。

### 1.3 拟人化程度（anthropomorphism）
| 指标 | 数值 |
|------|------|
| 综合拟人评分（四要素+口癖+内容，满分1.0） | **0.65** |
| 四要素至少出现 1 项的比例 | 0.857 |
| 完整三要素（动作+神态+内心）比例 | **0.071**（仅 7%） |
| 猫娘口癖率（喵/呀/呜/哼/杂鱼） | **0.964** |
| 同问非复读率（10 次「我好累」→ 9 种不同回复） | **0.964** |

> 结论：人格口吻极强（口癖 96%、非复读 96%），但"完整四要素"较少出现（引擎按概率随机脱落动作/内心，属刻意多样化，非缺陷）。

### 1.4 聊天边界 / 回复覆盖度（coverage）
| 指标 | 数值 | 说明 |
|------|------|------|
| 域外(OOD)测试集 | 7 条（写代码/数学/量子/翻译/电影/天气/股市） | 预期应**诚实降级** |
| OOD 误命中（假阳性，错误当命中） | **6 / 7** | ⚠️ 严重缺陷 |
| OOD 诚实降级率 | **1 / 7 = 0.143** | 仅"1+1等于几"正确回退 |
| 边界测试集 | 9 条（空/空白/长重复/emoji/乱码/攻击/超长/标点/换行） | 预期**不崩溃** |
| 边界崩溃数 | **0** | ✅ 鲁棒，零异常 |
| 边界优雅处理率 | **1.0** | 全部不崩溃（空/乱码等正确降级） |

> ⚠️ **重点局限（诚实披露）**：OOD 误命中率高达 **85.7%**——域外问题（如"帮我写Python代码"）被错误召回为猫娘回复（命中"想开party吗"），而非诚实回退 LLM。根因见第三节。

### 1.5 随机性（非复读补充验证）
- 同问「我好累」10 次 → **9 种不同回复**（动作/神态/尾字 喵呀·喵哼·喵喵 轮换）。非复读达标。

## 二、等效多少 B 模型参考（含模型种类）

本引擎是**检索缝合人格桩**，**不是生成式 LLM**，故"等效 B 数"须分维度类比，不能给单一数字。下表给出可对照的真实模型种类：

| 维度 | 本引擎实测 | 等效模型档位 | 具体模型种类参考 |
|------|-----------|-------------|------------------|
| **延迟/吞吐** | 2.15 ms/回复（p99<4ms） | 查表级，无推理开销 | 比任何本地 LLM 快 2–3 数量级；Qwen2.5-0.5B-Instruct（CPU llama.cpp）≈ 数百 ms~数秒/回复（逐 token） |
| **域内拟真度** | 四要素 86%·口癖 96%·非复读 96% | **≈ 0.5B–1.5B 域微调对话模型** | Qwen2.5-0.5B-Instruct / Qwen2.5-1.5B-Instruct + 梦瑶 LoRA；ChatGLM3-0.5B / MiniCPM-1B / Phi-3-mini 角色微调 |
| **域内命中率** | 89% recognized | ≈ 小模型窄域微调后水平 | 同上档位 |
| **域外诚实度** | 仅 14% 正确降级 | **弱于** 0.5B 模型 | 真实 0.5B 模型会尝试回答（可能错但至少不"伪装命中"）；本引擎应回退却常误触发 |
| **泛化/推理** | 0（纯检索，无推理） | ≈ 0B 通用智能 | 必须回退 ≥7B 通用模型（你现有 GLM-4 / DeepSeek-V3 via TokenHub） |

### 综合锚定
> 在「梦瑶猫娘」这一 **619 模式窄域**内，聊天拟真度**等效于一个 0.5B–1.5B 的域专属微调对话模型**（如 Qwen2.5-1.5B-Instruct 接梦瑶 LoRA）。
> 但它是检索缝合桩，**无推理、零泛化、域外诚实度偏弱**，因此**整体智能远不及 7B+ 通用模型**。
> **最佳实践**：本引擎作「域内快桩」（<4ms、人格强）+ 一个 ≥7B 通用 LLM（GLM-4 / DeepSeek）作「域外大脑」，由 `suggest_llm` 信号路由。

## 三、OOD 误命中根因（真实缺陷分析）

`engine.py` 的识别判定：
```python
if not scored or (len(scored) > 1 and scored[0][1] < max(scored[1][1] * 1.05, 0.02)):
    return self._fallback(...)   # 否则视为命中
```
问题：
1. **相对阈值过松**：top1 只需比 top2 高 5%（×1.05）即放行。任何多字查询在 619 文档上都会有"相对领先"的文档，故 OOD 几乎必过。
2. **绝对阈值失效**：`0.02` 分形同虚设——BM25+n-gram 对多字查询天然给 5~14 分，远低于"无匹配"应有的近 0。
3. ** lexical 假阳性**：字 n-gram 对"帮我写Python代码"×"想开party吗"产生巧合重叠（共享字），BM25 误给 7.24 分。

实测误命中样例（top1 分 / 命中语料）：
```
"帮我写一段 Python 快速排序代码" → 7.25 / 想开party吗   (领先比1.61)
"量子力学的基本原理是什么"       → 9.92 / 你的口癖是什么 (领先比1.57)
"推荐一部好看的科幻电影"         → 9.63 / 你喜欢看电影吗 (领先比1.33)
"明天北京天气怎么样"             → 12.33/ 今天过得怎么样 (领先比1.24)
"今天股市涨了吗"                 → 5.69 / 想逛超市吗     (领先比1.15)
```
（仅 "1+1等于几" 因 top1==top2 完全平局 → 领先比 1.0 → 正确降级）

## 五、结论

本引擎在**域内**（梦瑶 619 模式）表现扎实：延迟亚 4ms、人格强（口癖 96%、非复读 96%）、命中率 89%，**等效 0.5B–1.5B 域微调对话模型**；边界零崩溃（鲁棒性满分）。

但 **OOD 诚实度是真实短板**（85.7% 误命中），说明它**不能独立替代通用 LLM**，必须配合 ≥7B 通用模型（GLM-4 / DeepSeek）做域外大脑。这是检索缝合架构的固有边界，非调参可彻底消除——若要域外也"答得对"，上 bge 语义升级或路由到 LLM 是必经之路。

> 所有数字均来自 `bench_chat_v1.0.py` 真实运行（系统 Python 3.10 零依赖），未做任何美化。
