## 一、核心思路：一个地址，凭据决定账号

服务端只开了**一个**共享入口：

```
\\192.168.20.252\palm
```

**用哪个账号登录，就进哪个账号的个人域**（服务端 `path = /mnt/storage/private/%U`，`%U` = 登录用户名）。

| `[REDACTED_ACCOUNT]` | [REDACTED_ACCOUNT] 的个人域 | `[REDACTED_PASSWORD]` |
| `321801` | 321801 的个人域 | `[REDACTED_PASSWORD]` |
| `321802` | 321802 的个人域 | `[REDACTED_PASSWORD]` |
| `321803` | 321803 的个人域 | `[REDACTED_PASSWORD]` |

✅ **能显示真实容量**（实测 `4,093.6 GB`）——这是 SMB 相对 WebDAV 的核心优势。

## 二、脚本清单

| 脚本 | 作用 |
|---|---|
| `mount-Z-[REDACTED_ACCOUNT].cmd` | 以 **[REDACTED_ACCOUNT]** 身份挂 Z: |
| `mount-Z-321801.cmd` ~ `mount-Z-321805.cmd` | 以对应账号身份挂 Z: |
| **`mount-Z-ask.cmd`** | ⭐ **提示你输入账号+密码**，输完自动切到该账号（同一地址） |
| `unmount-Z.cmd` | 断开 Z: |

**用法**：双击即可。脚本会**先清空所有网络连接**再挂，所以随便重复跑、随便换账号都不会冲突。

---

## 三、为什么必须先"清空所有网络连接"（重要）

Windows 有个限制：**同一台服务器，同一时间只允许一套凭据**。
如果你已经用 A 账号连过 `192.168.20.252`，再想用 B 账号连，会报：

```
发生系统错误 1219。
不允许一个用户使用一个以上用户名与服务器或共享资源的多重连接。
```

**解决办法**：先断开与该服务器的所有连接，再用新凭据连。
脚本里已经内置了这一步（`net use * /delete /y`）。
> ⚠️ 注意：这条命令会清掉**所有**网络驱动器连接（不只 Z:），换账号时心里有数。

## 四、不用脚本：右键两步（同样带容量）

1. `此电脑` → 右键 → **「映射网络驱动器」**（**不是**"添加一个网络位置"）
2. 驱动器选 `Z:` → 文件夹填 `\\192.168.20.252\palm`
3. 勾选 **"使用其他凭据"** → 输入账号名（如 `321801`）+ 密码 `[REDACTED_PASSWORD]` → 完成

**换账号**：先右键 Z: →「断开连接」，再重复上面步骤用另一个账号登录。

> ❓「添加一个网络位置」为什么不行？它生成的是**快捷方式**，没有盘符，所以**不显示容量**。

## 五、把凭据存进系统（可选，省得每次输密码）

```bat
cmdkey /add:192.168.20.252 /user:321801 /pass:[REDACTED_PASSWORD]
net use Z: \\192.168.20.252\palm /persistent:yes
```
凭据会存进 Windows「凭据管理器」，之后 `net use` 就不用带密码了。
查看/删除：控制面板 → 凭据管理器 → Windows 凭据；或 `cmdkey /list` / `cmdkey /delete:192.168.20.252`

## 六、盘里那个「1-共享文件夹」

- 每个账号的盘里都有 **`1-共享文件夹`**（`1-` 前缀让它永远排最前）。
- 它是**所有人共用的公共区**，各账号看到的是同一份内容。
- **不可改名、不可删除**（服务端已加保护，会报 `Permission denied`）。
- 个人域 ↔ 共享 之间"移动"文件时，服务端**自动改成复制**（源文件保留）。

```
CT107 192.168.20.252
├─ SMB  [palm]  path=/mnt/storage/private/%U   凭据决定账号   hosts allow=192.168.20.0/24
│       另有 6 个旧的按账号共享(321801…/[REDACTED_ACCOUNT])，免密，保留作备用
├─ WebDAV  已全部停用(8092~8097 关闭)
└─ 存储  /mnt/palm 4.0T ── private/<账号> 个人域
                          └ public 共享区(bind 挂载到各账号的「1-共享文件夹」)
```

**网络要求**：设备需能访问 `192.168.20.0/24`。
`[palm]` 放行整个网段，**新设备不用再单独加白名单**。

# 附录 A · 纯鼠标（UI）挂载步骤

## A.1 首次挂载
1. 打开 **此电脑**（Win+E）
2. 顶部工具栏点 **⋯**（或空白处右键）→ 选 **「映射网络驱动器」**
   > ⚠️ 一定选 **「映射网络驱动器」**；**不要**选「添加一个网络位置」——
   > 后者生成的是**快捷方式**，没有盘符、**不显示容量**。
3. 弹窗里填：
   - **驱动器**：`Z:`
   - **文件夹**：`\\192.168.20.252\palm`
   - 勾 **「使用其他凭据」**（可选，见 A.2）
   - 勾 **「登录时重新连接」**
4. 点 **完成**。若弹出凭据框 → 用户名填 **账号**（如 `[REDACTED_ACCOUNT]`），密码 `[REDACTED_PASSWORD]`。

## A.2 怎么用"其他凭据"换账号
同一个地址 `\\192.168.20.252\palm`，**用户名填谁就进谁的空间**：

| 用户名 | 进入 |
|---|---|
| `[REDACTED_ACCOUNT]` | [REDACTED_ACCOUNT] 的个人域 |
| `321801` … `321805` | 对应账号的个人域 |

密码统一 `[REDACTED_PASSWORD]`。

## A.3 换账号（⚠️ 必须先断开）
Windows 限制：**同一台服务器同时只认一套凭据**，直接换会报 `系统错误 1219`。
所以顺序必须是：
1. 右键 Z: → **「断开连接」**
2. （保险起见）命令提示符里跑一次 `net use * /delete /y`
3. 再按 A.1 重新映射，凭据填新账号

## A.4 断开 / 清理
- **断开**：右键 Z: → **「断开连接」**
- ❓**为什么右键没有「删除」？**
  因为它是**映射的网络驱动器**（有盘符）——Windows 对"连接"只提供**「断开连接」**。
  **只有"网络位置"快捷方式**（用"添加网络位置"建的）右键才有「删除」。
- **红叉（❌）是什么意思？**
  说明这个盘符**连接已断开**，或是个**残影**（之前删过映射，资源管理器没刷新）。
  按 **F5** 刷新，或重启一次 `explorer.exe` 即可消失。
- 彻底清理残影（管理员不需要，普通即可）：
  ```bat
  net use * /delete /y
  ```
  若图标仍在，删注册表项 `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\MountPoints2` 下对应的 `##192.168.20.252#*`

# 附录 B · 两个常见疑问

## B.1 为什么"输入网络凭据"对话框默认填了某个账号？
因为 **Windows 凭据管理器里存了一条该服务器的凭据**。查看：
```bat
cmdkey /list:192.168.20.252
```
如果看到 `用户: [REDACTED_ACCOUNT]` 之类的条目，就是它在自动填、**并且 Windows 会自动拿它去连**——
这也是"想换账号却报 1219"的元凶。

**删掉它**（之后就空白了，你填谁就是谁）：
```bat
cmdkey /delete:192.168.20.252
```
> 反过来：在凭据框里勾了 **"记住我的凭据"**，它就会被重新存进去。

## B.2 "断开连接" + "重启资源管理器"，算删干净了吗？
**算——但要两步都做，顺序别搞反：**

| 动作 | 作用 |
|---|---|
| 右键 → **「断开连接」** | **真正删掉映射**（关键，不能省） |
| 重启 **explorer.exe** | **刷新界面**，让幽灵图标消失 |

- ✅ 两步都做 → 删干净
- ❌ 只重启 explorer、没断开 → 映射还在，图标刷新完又回来
- ❌ 只断开、不重启 → 映射没了，但图标可能还赖在"此电脑"里（按 F5 也能刷掉）

> 注意：是重启 **explorer.exe（资源管理器）**，不是重启"任务管理器"本身。
> 任务管理器只是你用来重启 explorer 的工具。
